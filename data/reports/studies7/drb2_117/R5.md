# 空而不空的佛性：吉藏「中道佛性」思想研究

## 摘要

吉藏（549—623）是三论宗的集大成者，以弘扬「缘起性空」的中观学为终身志业；然而他在《大乘玄论》《涅槃经游意》等著作中又明确肯定《涅槃经》「佛性常住」「一切众生悉有佛性」之教，并判《涅槃》为「众经之密藏」。表面上看，讲「空」的宗匠与讲「常住不空」的经教之间似有张力。本报告依据吉藏现存的疏论原文，论证这一张力在其思想体系内部已被系统地化解：吉藏所谓佛性，不是任何意义上的实体（不是众生、不是心识、不是阿梨耶识、不是某种凝固的「理」），而是「**非真非俗之中道**」「**第一义空**」本身；所谓「常住」，不是与无常相对的世俗之常，而是对治「无常病」的方便言说，法身本身「未曾常与无常」。因此，「佛性常住」恰恰是空的彻底化——横绝百非、四句常寂——而不是对空的否定；二者的统一枢纽在于「法身即中道实相」与「隐显随缘」的如来藏解释学。在实践层面，佛性论为一乘思想提供本体论依据（「一乘者，乃是佛性之大宗」），并以「知己有佛性故发菩提心、知他有佛性故不造十恶」的方式落实为具体的修行激励。本报告分五部分：一、吉藏其人其学；二、他所破斥的十一家佛性旧说及其批判逻辑；三、「中道佛性」正见的正面建构；四、「常住」与「空」如何融通；五、此一理论的实践意义。

## 一、人物背景：吉藏与三论宗

### 1.1 生平与著述

吉藏（549—623），俗姓安，其先世为安息国人，故时人亦称「胡吉藏」。他生于金陵（今南京），幼年时由真谛三藏为其取名「吉藏」，七岁（一说十三岁）投兴皇寺法朗门下出家，十九岁即能登座复讲，崭露头角。隋朝平定江南之后，他移住会稽（今浙江绍兴）秦望山嘉祥寺，在此讲经十五年，听众常达千余人，世称「**嘉祥大师**」。开皇末年，晋王杨广（即后来的隋炀帝）召其入住扬州慧日寺；公元599年前后随杨广入长安，住日严寺，在此完成了对《中论》《百论》《十二门论》的注疏——《中论疏》成于仁寿二年（602），《百论疏》与《十二门论疏》成于大业四年（608），三论宗的义学体系至此正式奠定。大业年间他曾在长安与当时名僧僧粲论辩而获胜，声望极隆。入唐以后，唐高祖设立「十大德」统领僧务，吉藏名列其中；武德六年（623）五月圆寂，世寿七十五，临终犹作《死不怖论》，以般若空观安顿死亡，落笔而卒。其生平主要见于《续高僧传·吉藏传》，近人汤用彤、吕澂等皆有考述（[劝学网·吕澂《中国佛教人物》](https://www.quanxue.cn/ct_fojia/zgfojiarw/zgfojiarw30.html)，[汤用彤《隋唐佛教史稿》](https://www.diancang.xyz/xueshuzaji/18377/340600.html)）。

吉藏一生著述宏富，现存及佚失合计四十余种。与佛性论直接相关的核心著作包括：**《大乘玄论》**五卷（其中卷三「佛性义」十门是汉传佛教佛性思想史上最重要的文献之一）、**《涅槃经游意》**一卷（对《大般涅槃经》宗要的纲要性阐释）、**《法华玄论》**十卷（论一乘与佛性的关系）、**《中观论疏》**（《中论》疏）、**《百论疏》**、**《胜鬘宝窟》**（《胜鬘经》疏，论如来藏与佛性）等，均收入大正藏（T1853、T1768、T1720、T1824、T1827、T1744）（[CBETA 中华电子佛典](https://cbetaonline.dila.edu.tw/)，[百度百科·大乘玄论](https://baike.baidu.com/item/%E5%A4%A7%E4%B9%98%E7%8E%84%E8%AE%BA/4925788)）。据载他讲三论百余遍、讲《法华》三百余遍，其学说通过弟子慧灌东传日本，慧灌成为日本三论宗初祖，三论学由此成为东亚佛教义学的重要源头之一（[中国佛学院·三论宗师资传承](http://www.zgfxy.cn/yjcg/zgx/fy/zdsjq2001n/content_897)）。

### 1.2 学派定位与思想史位置

吉藏所承的三论学，远绍印度龙树、提婆的中观学派，经鸠摩罗什译出《中论》《百论》《十二门论》及《般若经》而传入中土；罗什门下僧肇、僧睿开其端，此后经僧朗、僧诠、法朗三代在摄山、兴皇一线传承，至吉藏而集大成。吉藏自述其佛性义师承：「**一家相传**」上溯河西道朗——即参与昙无谶译《大般涅槃经》、并为其作序的凉州学者——这一法脉使三论学与涅槃学在吉藏身上合流（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[中国宗教学术网·关河旧说考辨](http://iwr.cass.cn/yjly/fjyj/lw/202209/W020220916517120657056.pdf)）。在判教上，吉藏立二藏（声闻藏、菩萨藏）三轮（根本法轮《华严》、枝末法轮、摄末归本法轮《法华》），又以「无所得」为诸经共宗，而特别指出「**《涅槃》广明佛性常住，为斥无常之病为其正宗**」，承认涅槃佛性教在大乘教相中的最高对治地位（[《大乘玄论》卷五](https://cbetaonline.dila.edu.tw/T45n1853_005)，[华文哲学百科·汉传佛教佛性思想](https://mephilosophy.ccu.edu.tw/entry.php?entry_name=%E6%BC%A2%E5%82%B3%E4%BD%9B%E6%95%99%E4%BD%9B%E6%80%A7%E6%80%9D%E6%83%B3)）。

在思想史上，吉藏被公认为三论宗的实际创立者与最高峰。汤用彤称其为「中国三论宗之元匠」，吕澂则评价「三论的学说传到吉藏便打开了局面」，意谓三论学到吉藏手中才真正成为有判教、有方法论、有完整著述体系的宗派（[汤用彤](https://www.diancang.xyz/xueshuzaji/18377/340600.html)，[劝学网·吕澂](https://www.quanxue.cn/ct_fojia/zgfojiarw/zgfojiarw30.html)）。吉藏所处的时代，正是南北朝佛性论争的高潮期：自《大般涅槃经》昙无谶译本（421年）流传以来，「佛性是什么」「众生是否皆有佛性」「佛性本有还是始有」成为南北义学僧争论的中心议题，《大乘玄论》所录「正因佛性」诸说即达十一家之多。吉藏的佛性论正是对这一时代论争的总回应与总批判：他以中观「无所得」的破执方法清洗了所有实体化的佛性说，又以「中道佛性」重建了《涅槃经》常住教说的正当性，从而在空的哲学与有的宗教之间完成了一次高难度的理论综合（[洪修平《中国佛教文化历程》相关论述](https://www.aisixiang.com/data/148375.html)，[内明·吉藏佛性思想](https://www.fjdh.cn/wumin/2009/04/21314864071.html)）。

## 二、破斥旧说：吉藏对十一家佛性论的批判

### 2.1 十一家旧说的全景与分类

《大般涅槃经》卷二十七〈师子吼菩萨品〉明说「佛性者名第一义空」「一切众生悉有佛性」，但「佛性」的所指究竟为何，南北朝义学并无共识。吉藏在《大乘玄论》卷三「佛性义」中系统整理了此前诸师的「正因佛性」说，共列**十一家**；均正《大乘四论玄义》所记亦与之相发明。所谓「正因佛性」，是相对于「缘因佛性」（促成佛性显发的修行条件）而言的成佛根本依据——追问正因佛性，即追问「众生成佛的终极根据是什么」。吉藏将十一家归纳为三大类：**假实说**（以众生或六法为正因）、**心识说**（以心、真神、阿梨耶识等为正因）、**理境说**（以当果、得佛之理、真谛、第一义空为正因）。兹列表如下（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[中华佛学研究所学报·吉藏《大乘玄论》之中道佛性](https://www.chibs.edu.tw/ch_html/chbs/16/chbs1601.pdf)）：

| 类别 | 家数 | 正因佛性主张 | 代表思路 | 吉藏批判要点 |
|---|---|---|---|---|
| **假实说** | 第一家 | 以**众生**为正因佛性 | 经言「一切众生悉有佛性」，故众生即佛性 | 「有众生相则非菩萨」，众生是妄想所成，岂能为正因 |
| | 第二家 | 以**六法**（五阴及假人）为正因 | 六法即构成众生的元素 | 六法是果报生灭法，非常住佛性 |
| **心识说** | 第三家 | 以**心**为正因佛性 | 经言「有心必得菩提」 | 经意是「有心之人必得菩提」，非谓心即佛性；心是无常、佛性是常，故心非佛性 |
| | 第四家 | 以**冥传不朽**为正因 | 心神冥默相传、历劫不朽 | 堕「神我常住」见，同外道 |
| | 第五家 | 以**避苦求乐**（厌苦求乐的本能）为正因 | 《胜鬘经》「若无如来藏者，不得厌苦乐求涅槃」 | 经意是「由如来藏力故众生能厌苦求乐」，非谓厌求之心即佛性；因果颠倒 |
| | 第六家 | 以**真神**为正因 | 众生身中有真实神主 | 即外道神我之翻版，有「有所得」之过 |
| | 第七家 | 以**阿梨耶识自性清净心**为正因 | 地论、摄论学系以第八识为净识本体 | 《摄大乘论》明言阿梨耶识是「无明母、生死根本」，诸识皆「有所得、五眼所不见」，故非佛性 |
| **理境说** | 第八家 | 以**当果**（未来当得之佛果）为正因 | 约未来果位说众生有佛性 | 当果在未来，现前无有，堕「始有」执 |
| | 第九家 | 以**得佛之理**为正因 | 众生有「可成佛之理」 | 理若是定有之理，则堕常见；且理不自成，何名为因 |
| | 第十家 | 以**真谛**为正因 | 真谛空理为佛性 | 但境非智，是「偏道」 |
| | 第十一家 | 以**第一义空**为正因 | 第一义空之理为佛性 | 此说最接近正见，然旧解「但境而非智」，仍是偏道 |

十一家之说，在吉藏看来并非全无经教依据——每一家都能引经据典；问题出在诸师都把「佛性」理解为一个可以指认、可以安立的**实体或定法**（「有所得」），从而堕入「常、无常、亦常亦无常、非常非无常」等四句分别之中。吉藏的批判方法论正是中观学的看家本领：**破邪即是显正**，离四句、绝百非，不以任何一法为定实的正因。值得注意的是，第十一家「第一义空为佛性」与吉藏自宗表述几乎相同，但吉藏仍判其为「偏道」，理由是其第一义空只是客观的空理（境），没有与般若智慧打成一片；这一点为下文第三节「确立正见」埋下了关键伏笔（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[董群论吉藏中道佛性（讲座纪要）](https://roll.sohu.com/a/606689050_121124751)）。

### 2.2 对「众生」与「六法」说的破斥

第一家以「众生」为正因佛性，其经证是《涅槃经》「一切众生悉有佛性」——既然众生悉有佛性，索性即以众生为佛性。吉藏的反诘极为锋利：「**经既说言有众生相则非菩萨，宁得以众生为正因耶？故知有众生者皆是妄想。**」《金刚经》明言「若菩萨有我相、人相、众生相、寿者相，即非菩萨」，「众生」本是妄想分别所成的假名，若以妄想为成佛的正因，等于以幻为实，正是中观学所破的第一种「有所得」（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)）。

第二家以「六法」（五阴与假人）为正因，思路是以构成众生的元素为佛性。吉藏指出，五阴是生灭果报之法，刹那迁流，而佛性「常恒无有变易」；以无常之阴身为常住之佛性，直接与经教相违。更根本的是，无论「众生」还是「六法」，都属于「假、实」二法的范畴，而三论学早已证明假法与实法皆无自性、皆不可执：执假人则为凡夫见，执实法（阴、入、界）则为二乘见。佛性若是正因，必须超出假实二种可执之法，否则仍是生死法而非涅槃因。这一批判确立了一个贯穿全篇的原则：**正因佛性不能是任何被认取的对象**——凡可以被指认为「此即是」的，便已落在无所得的空观之外（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[华文哲学百科](https://mephilosophy.ccu.edu.tw/entry.php?entry_name=%E6%BC%A2%E5%82%B3%E4%BD%9B%E6%95%99%E4%BD%9B%E6%80%A7%E6%80%9D%E6%83%B3)）。

### 2.3 对「心识」诸说的破斥：心、真神、趋乐避苦与阿梨耶识

心识说五家是南北朝最流行的佛性论，也是吉藏批判着墨最多之处。第三家以「心」为佛性，引经「有心必得菩提」。吉藏的辨正区分了语法与义理：「**经云『有心必得菩提』者，此明有心之者必得菩提，何时言心是正因佛性耶……心是无常、佛性常，故心非佛性也。**」——经文说的是「有心（识）的众生必然能够成就菩提」，主词是「有心者」而非「心」本身；何况心的生灭无常与佛性的常恒不变直接相违，两者不可等同（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)）。

第五家以「避苦求乐」——众生厌离痛苦、趋求安乐的本能——为正因佛性，所据是《胜鬘经》「若无如来藏者，不得厌苦乐求涅槃」。吉藏指出这是把经文的因果读反了：「**《胜鬘经》云『若无如来藏者，不得厌苦乐求涅槃』者，此正明由如来藏佛性力故，所以众生得厌苦求乐。何时明厌苦求乐是正因佛性耶？**」经意是：因为有如来藏（佛性）作为内在依据，众生才可能厌苦求乐；厌求之心是佛性之「用」的发动，而非佛性之「体」本身。把功能性的心理倾向当作本体性的正因，是因果倒置之误。第四家「冥传不朽」与第六家「真神」，在吉藏看来则已越出佛教边界：以历劫不朽的神识或身中真神为佛性，实质上与外道「神我常住」论无异，违背无我与缘起的基本法印（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[中华佛学研究所学报](https://www.chibs.edu.tw/ch_html/chbs/16/chbs1601.pdf)）。

第七家以「阿梨耶识自性清净心」为正因，代表了当时地论师与摄论师一系的唯识古学。吉藏的驳斥直接引对方所宗的《摄大乘论》：「**摄大乘论云（阿梨耶识）是无明母、生死根本。故知六识、七识乃至八、九，设使百千无量诸识，皆非佛性。何以故？皆是有所得、五眼所不见故。**」阿梨耶识在《摄论》自身的定义中是无明的母体、生死的根柢，以生死根本为成佛正因，自相矛盾；而从三论立场看，一切「识」都属有所得的妄分别范畴，是五眼所不能照见的虚妄法（五眼所见唯实相），故无论立八识、九识乃至无量诸识，都不可能触及正因佛性。这一批判锋芒实指当时方兴未艾的唯识学本体化倾向，显示了吉藏维护中观「无所得」立场的彻底性（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[董群讲座](https://roll.sohu.com/a/606689050_121124751)）。

### 2.4 对「理境」诸说的破斥及其批判逻辑的总结构

理境说四家以抽象的「理」为佛性：当果（第八家）约未来佛果说佛性，得佛之理（第九家）以「众生有成佛之理」为佛性，真谛（第十家）与第一义空（第十一家）则以空理为佛性。吉藏对前两家的批评是：「当果」在未来，现前无有，则众生现时并无佛性，既违背「悉有」之经教，又堕入「始有」的定执；「得佛之理」若是一客观凝固的理，则理不自成、不能为因，且定有之理即是常见。对后两家的批评则最为微妙：真谛、第一义空确实是般若学的核心，以之为佛性看似无可非议；但吉藏指出，旧师所明的第一义空「**但境而非智**」——只是被观照的空寂之理，而没有与能照的智慧融为一体——「**斯是偏道**」，即偏执于境一边的片面之道，而非境智圆融的中道（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)）。

纵观十一家批判，其内在逻辑高度统一，可归纳为三判：**（一）凡有所指认者皆非佛性**——众生、六法、心、识、理，皆可被指认为「此即是佛性」，而正因佛性恰是「无所得」、不可指认的；**（二）凡堕四句者皆非佛性**——或常或无常、或本有或始有、或因或果，诸说各执一句，而正因佛性离四句、绝百非；**（三）凡偏一边者皆非佛性**——但境非智、但智非境、但常非无常，皆是偏道，正因佛性必须是境智不二、因果双非的中道。由此，批判本身就导向了正面结论：破尽十一家之后，唯一剩下的可能性是以「中道」为佛性。吉藏总结道：「**若悟诸法平等无二、无是无非者，十一家所说并得是正因佛性**」——一旦悟入无所得的中道，十一家所说皆成方便；反之，若有所得，则无一可取。破与立、遮与诠，在这里完全是一回事（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[内明](https://www.fjdh.cn/wumin/2009/04/21314864071.html)）。

## 三、确立正见：「中道佛性」的正面建构

### 3.1 非真非俗之中道为正因佛性

破斥既毕，吉藏给出自家定义：「**是故今明：第一义空名为佛性。不见空与不空、不见智与不智，无常无断，名为中道，只以此为中道佛性也。若以此足前十一师，则成第十二解。然若识正道，知道无有一，岂复有二释于其间哉。**」这段纲领性文字有三层意思：其一，正面立义——以第一义空为佛性，但此第一义空必须是「不见空与不空」的彻底空，即连「空」本身亦不可执取；其二，方法论说明——「无常无断名为中道」，中道的内涵就是离常无常、空不空等一切二边；其三，判摄意识——自家之说若凑数可列为第十二家，但严格说来「道无有一」，正道本无「一家」「二家」之分，一旦识得正道，便无所谓与其他十一家并列的第十二解。故吉藏自宗的总纲是：「**非真非俗中道，为正因佛性也。**」（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)）

这一立义直接依据《涅槃经·师子吼品》的经文：「佛性者名第一义空，第一义空名为智慧。所言空者，不见空与不空；智者，见空及与不空……见一切空、不见不空，不名中道……中道者名为佛性。以是义故，佛性常恒无有变易。」吉藏对这段经文的解读紧扣两点：第一，佛性之所以是「第一义空」，在于此空不是与「不空」相对的偏空（小乘的灰断之空），而是「不见空与不空」——对空与不空两边都不执取、都不「见」（见即是执）——的绝待之空；第二，此空即是中道，「非因非果，名为佛性；非因果故，常恒无变」。由此，「佛性=第一义空=中道」三位一体，构成了吉藏佛性论的骨架（[《大般涅槃经》卷二十七](https://cbetaonline.dila.edu.tw/T12n374_027)，[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)）。

### 3.2 境智不二：第一义空即般若智慧

吉藏佛性论最精微之处，在于他对「第一义空」的重新界定：「**而言第一义空为佛性者，非是由来所辨第一义空。彼明第一义空，但境而非智，斯是偏道。今言智慧，亦非由来所明之智慧。彼明智慧，但智而非境，斯亦是偏道义，非谓中道也。**」旧师的第一义空只是所观的空境，旧师的般若智慧只是能观的心智——境与智分立，两者皆是偏道。吉藏的第一义空则是「**说境为智、说智为境**」的境智不二：空境不离般若之智，般若之智即是空境之自相显发；离开境没有智，离开智也无所谓境。正是在这个意义上，《涅槃经》才能说「佛性者名第一义空，第一义空名为智慧」——空与智的互名，正是中道佛性的本质规定（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[中华佛学研究所学报](https://www.chibs.edu.tw/ch_html/chbs/16/chbs1601.pdf)）。

这一「境智不二」的结构，使吉藏的佛性论同时避开了两种陷阱：若佛性只是客观空理（但境非智），则它成为与众生修行的觉照活动无关的死理，无法解释「见性成佛」；若佛性只是主观心识（但智非境），则堕回已被破斥的「心为佛性」旧说，且无法解释佛性的遍在性与常住性。境智不二的中道佛性，既不是实体性的「有」，也不是虚无性的「空」，而是能所双泯、真俗俱融的实相本身。吉藏又以「种子」譬喻其功能义：「**佛性者，即是三菩提中道种子也。**」——佛性是无上正觉（三菩提）的「中道种子」，「种子」表明佛性具足令众生成佛的功能性根据，而「中道」限定词表明这种子不是实体性的因，不是因缘所生法的因，而是「非因非果」意义上的正因：《胜鬘宝窟》进一步发挥为「**佛性名为中道种子，中道之法名之为佛……由佛性本是中道，中道未现名种子，中道显现目之为佛**」，佛性之与佛，只是中道的隐与显，体上无二无别（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[《胜鬘宝窟》](https://cbetaonline.dila.edu.tw/T37n1744)）。

### 3.3 会通诸经：佛性的异名与「一理」判摄

确立中道佛性之后，吉藏在「会教门」中处理了佛性与其余大乘核心概念的关系，给出了著名的佛性异名论：「**于《涅槃经》中名为佛性，则于《华严》名为法界，于《胜鬘》中名为如来藏自性清净心……《法华》名为一道一乘，《大品》名为般若、法性，《维摩》名为无住、实际。**」佛性、法界、如来藏、一乘、般若、法性、无住、实际——诸经所说的这些名目，所指本是同一个中道实相，只是随教随缘、立名不同。在《涅槃经游意》中他又举「五类」之说：「一法界、二法性、三法身、四般若、五佛性」，五名同体、随义差别。这一判摄有双重效果：对内，它把《涅槃经》的佛性教完全纳入般若学的概念网络，佛性不再是一个外来的、与空学异质的实体概念，而是实相的又一异名；对外，它为三论宗「无所得为宗」的判教提供了概念统一性——诸经差异只是言辞施设，「**无所得为经宗**」则一以贯之（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[《涅槃经游意》](https://cbetaonline.dila.edu.tw/T38n1768_001)）。

特别值得注意的是吉藏对「一道」的三义分疏：「**只是一道，三义说之。无境不照义故名般若，真极无二义称为妙法，常恒不变义目为涅槃。**」同一个中道实相：就它能遍照万境而言叫般若，就它真实至极、无二无别而言叫妙法（《法华》），就它常恒不变而言叫涅槃（《涅槃》）。于是《般若》《法华》《涅槃》三部大经在「一道」之下完全贯通——般若之照、法华之妙、涅槃之常，是同体的三面。这正是回答「空宗大师何以肯认常住佛性」的枢纽所在：在吉藏的概念体系中，「般若」与「涅槃之常」从来不是两种教义，而是同一中道的不同面向；说空与说常，依所治之病而不同，就所显之体则无二（[《大乘玄论》](https://cbetaonline.dila.edu.tw/T45n1853_005)，[唐君毅论吉藏](https://www.diancang.xyz/rulizhexue/17358/330214.html)）。

## 四、常住与空：「佛性常住」如何与缘起性空相融通

### 4.1 问题的提出：两种「常」的辨析

《涅槃经》反复宣说「佛性常恒无有变易」「如来常住，无有变易」，而中观学的根本命题是「缘起性空」「诸法无常」。吉藏面对的核心难题是：佛性之「常」是哪一种常？它在何种意义上不与性空相违？《百论疏》记录了当时关于「常」的两种主要理解，即「**当现二常**」之争：「四北土，略论当现二常……一云定现常、一云定当常。」所谓**现常**（本有）：「明生死中已有法身，体用具足，现常义名之为有，为妄所覆故不现名为无果」——佛性法身在生死之中当下圆满具足，只是被妄想覆盖而不显现，犹如贫女宝藏、弊帛裹金；所谓**当常**（始有）：「当有于果名为有义，即时未有名为无果」——佛性是未来当来之果，现在尚未成就，须经修行方能证得。二说分别对应佛性论史上的「本有」与「始有」两大阵营（[《百论疏》卷上](https://cbetaonline.dila.edu.tw/T42n1827_001)，[《百论疏》卷下](https://cbetaonline.dila.edu.tw/T42n1827_003)，[researchmap·吉蔵による法身常住の理解について](https://researchmap.jp/sanronshu/published_papers/31709365/attachment_file.pdf)）。

对这两种「常」，吉藏的态度是**俱不取**：「实相何曾当、现，亦当亦现、非当非现四句耶？」——实相本身何曾有「当（来）」「现（在）」乃至「亦当亦现」「非当非现」等四句分别？定执现常，则佛性成为凝固的实体，近同外道神我，且无法解释修行之必要（若本已具足，何须修证）；定执当常，则佛性成为修成之作法，作法皆是无常，「始有」之常自相矛盾，且无法解释「一切众生悉有」之经教。两说各有所据、各有所病，病根相同：都把「常」理解为时间性的持续或实体的圆满，即在「常—无常」的对待框架内理解佛性。而吉藏要指出的恰恰是：**佛性之常不是对待意义上的常，而是超越常与无常之对待的中道**（[《百论疏》](https://cbetaonline.dila.edu.tw/T42n1827_001)，[华文哲学百科](https://mephilosophy.ccu.edu.tw/entry.php?entry_name=%E6%BC%A2%E5%82%B3%E4%BD%9B%E6%95%99%E4%BD%9B%E6%80%A7%E6%80%9D%E6%83%B3)）。

### 4.2 「非本非始，亦非当现」：佛性超四句而随缘说常

《大乘玄论》「本有始有门」给出吉藏的最终判摄：「**今一家相传明佛性义，非有非无、非本非始，亦非当现。**」又云：「**至论佛性，理实非本非始，但如来方便，为破众生无常病故，说言一切众生佛性本来自有……不但非是本始，亦非是非本非始。**」这段引文包含吉藏佛性论的双层结构：就实理而言，佛性「非本非始」——它既非本有（现常）亦非始有（当常）；就教化而言，如来为破众生「无常」之病态执著，方便宣说佛性本来自有、常住不变。甚至连「非本非始」这一遮诠表述本身也不可执实——「不但非是本始，亦非是非本非始」，遮遣亦遣，方是究竟（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)）。

由此，「佛性常住」的确切含义被揭示为**对治悉檀**（针对特定病症的药用教化）。《法华玄论》说得最明白：「**《涅槃》明常者，此是对治悉檀，非究竟说……昔破邪常故说无常，今斥无常是故说常。然如来身未曾常与无常，常无常方便用具足。**」佛教教化史上的次第是：先前为破外道、凡夫的「邪常」（神我、实体之常），佛说无常；其后为破二乘及偏执空者的「无常」病（灰身灭智、断灭之见），《涅槃经》说常。常与无常都是药，病去则药舍；如来的法身本身「未曾常与无常」——它超出常与无常的二元对立，却能具足地运用常与无常两种方便。《涅槃经游意》以「四双八只」总结此义：凡圣、常无常、隐显、半满，四对范畴都是方便施设；「**涅槃非常无常，常无常皆涅槃方便……虽无所有而无所不有……非常非无常，常无常具足也。**」经文「虽不常住，非念念灭」一句，正是「常无常两除」的经证：法身既不是定常（不常住），也不是断灭（非念念灭），离此二边即是中道（[《法华玄论》卷三](https://cbetaonline.dila.edu.tw/T34n1720_003)，[《涅槃经游意》](https://cbetaonline.dila.edu.tw/T38n1768_001)，[researchmap](https://researchmap.jp/sanronshu/published_papers/31709365/attachment_file.pdf)）。

那么「常恒不变」是否就完全落空了？并非如此。吉藏在「八味」释义中辨析：「不从缘生为常，始终真实为恒。」佛性之「常」的正面意义在于**不从缘生**——它不是因缘造作之法，故无生灭变异；这与缘起性空非但不矛盾，反而是同一命题的两面：正因为佛性（中道实相）不是任何「从缘所生」的个别事物，它才「常」（无生灭）；正因为一切从缘所生之法皆无自性（空），才显出那「不从缘生」的中道之常。换言之，**性空是就对治「自性有」而说，常住是就对治「断灭无」而说**；空所空掉的是自性之常（邪常），常所常住的是离言之实相——两者的靶子不同，所向一致。《中观论疏》卷十的总结最为圆熟：「**横绝百非、竖起四句，名为诸法实相，即是中道……又德无不圆名为不空，累无不寂称之为空，即是智见空及以不空，亦名佛性……若知百非本空、四句常寂，即佛性显，称为法身。**」——「累无不寂」谓之空（一切执累无不寂灭），「德无不圆」谓之不空（一切功德无不圆满）；空与不空不二，即是佛性；彻知百非本空、四句常寂之时，佛性便显现为法身。空性即是佛性的隐说，佛性即是空性的显说，二者本是一事（[《涅槃经游意》](https://cbetaonline.dila.edu.tw/T38n1768_001)，[《中观论疏》卷十](https://cbetaonline.dila.edu.tw/T42n1824_010)）。

### 4.3 法身论：统一「常住」与「性空」的枢纽

佛性常住与缘起性空的最终统一，落在吉藏的法身论上。《中观论疏》引《楞伽经》出**法身五名**：「谓真如、法性、实际、法界、法身」——法身即真如、法性、实际、法界的异名，亦即中道实相本身。法身不是一个在众生身中「住着」的实体性自我，而是诸法实相；说众生「有」佛性法身，不是说众生身中藏着一件常住之物，而是说诸法实相遍一切处、众生本在实相之中、迷悟之间别无他物（[《中观论疏》卷十](https://cbetaonline.dila.edu.tw/T42n1824_010)）。

由此，「隐显」说取代了「有无」说，成为法身—佛性论的解释框架。《法华玄论》云：「**隐名佛性、显名涅槃，亦隐名如来藏、显则成法身……然佛性未曾隐显，约众生不了故名为隐，若得了悟自为显也。**」《涅槃经游意》以箜篌之喉为喻：「**今明只迷故名隐名藏，岂尚别有此体可隐？只悟故名显，名法身无体可显……隐显并出于缘。**」——只是迷，故名为隐、名为「（如来）藏」，并非真有一物被隐藏；只是悟，故名为显、名为法身，并非真有一物被显出。隐与显都是就「缘」（迷悟的众生）而安立的假名，法身本身「未曾隐显」。这一解释学的精妙之处在于：它既保住了「一切众生悉有佛性」的宗教承诺（实相无所不在，迷时亦不失），又完全不需要预设任何实体性的「藏」——「藏」只是迷的别名，「佛性常住」只是实相不随迷悟而增减的另一种说法。缘起性空讲的就是诸法无自性、实相离四句；佛性常住讲的也是同一实相不堕断灭、不随妄缘而变。两者在「法身即中道实相」这一点上彻底合流（[《法华玄论》卷三](https://cbetaonline.dila.edu.tw/T34n1720_003)，[《涅槃经游意》](https://cbetaonline.dila.edu.tw/T38n1768_001)，[唐君毅](https://www.diancang.xyz/rulizhexue/17358/330214.html)）。

法身论还解决了「常」与三身说的衔接。《法华玄论》卷九辨三身寿量：「**一者法身无始终，即是无三世义；二者修因得果以为报佛，此有始无终义……三化身有始有终。**」法身无始无终、超出三世——这才是「常住」的严格所指，而此「无始无终」正是「未曾常与无常」的积极表达：不是时间中的无限延长，而是根本超出时间框架。报身有始无终（成佛起永不灭）、化身有始有终（随缘示现生灭），二者皆为法身随缘之用。同卷又辨「证常有二种：一者久已证常、二今始证常」，吸收本有、始有二说的合理因素而不堕其执：就法身之本然而言，常「久已」成就（摄入现常之义而不执实体）；就行者之证悟而言，是「今始」证得（摄入当常之义而不执新生）。常与无常、本与始、隐与显，一切对立在法身的中道实相中皆被双照双遣（[《法华玄论》卷九](https://cbetaonline.dila.edu.tw/T34n1720_009)，[researchmap](https://researchmap.jp/sanronshu/published_papers/31709365/attachment_file.pdf)）。

下表总摄两种「常」的辨析与吉藏的判摄：

| 维度 | 现常（本有）说 | 当常（始有）说 | 吉藏的中道判摄 |
|---|---|---|---|
| 基本主张 | 生死中已有法身，体用具足，为妄所覆而不现 | 当有于果、即时未有，修行方证 | 佛性「非本非始，亦非当现」，连「非本非始」亦不可执 |
| 经教依据 | 《涅槃》「一切众生悉有佛性」、如来藏诸喻 | 修行成佛的因果次第 | 二说皆是对治方便，非究竟实义 |
| 理论风险 | 堕常见、近外道神我；无法解释修行必要 | 堕断见之嫌、作法无常；无法解释「悉有」 | 超四句：「实相何曾当、现、亦当亦现、非当非现」 |
| 「常」的理解 | 时间中的圆满先在 | 未来时间中的获得 | 不从缘生、无始无终、未曾常与无常（对治悉檀） |
| 合理成分之吸收 | 「久已证常」——法身本然 | 「今始证常」——行者证悟 | 隐显随缘：迷名隐名藏，悟名显名法身，隐显并出于缘 |

至此，本报告开头提出的张力可以给出明确的解答：**吉藏承认「佛性常住」，但此「常」是离常无常二边的中道之常、是「不从缘生」的实相之常、是对治「无常病」的方便之常，唯独不是与无常相对的实体之常；他弘扬「缘起性空」，但此「空」是「累无不寂」而「德无不圆」的第一义空、是「不见空与不空」的绝待之空，唯独不是与「不空」相对的偏空。** 常超所治之「邪常」，空超偏执之「断空」；佛性即第一义空、第一义空即中道、中道即法身——在这一连串等式中，「常住」与「空」不是两个需要调和的命题，而是同一中道的两种随宜言说（[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[《中观论疏》卷十](https://cbetaonline.dila.edu.tw/T42n1824_010)，[洪修平](https://www.aisixiang.com/data/148375.html)）。

## 五、理论的实践意义：一乘的理据与修行的激励

### 5.1 佛性论作为一乘思想的本体论根据

吉藏佛性论绝非纯粹的形上学思辨，其首要实践指向是为**一乘**教说奠基。《法华玄论》与《大乘玄论》反复申明：「**一乘者，乃是佛性之大宗，众经之密藏，反三之妙术，归一之良药。**」一乘教（《法华》所显）主张三乘（声闻、缘觉、菩萨）终归一佛乘、一切众生皆当作佛；这一主张之所以可能，正因为一切众生皆有佛性——佛性是一乘的「大宗」（根本宗旨），反三归一的依据即在佛性遍在。吉藏又以「三乘（三种乘）」配佛性：「**乘有三种：理乘即是中道佛性，行乘即是缘因佛性，果乘即是果佛性。**」理乘是成佛的本体论根据（中道佛性），行乘是促成其显发的修行实践（缘因），果乘是修行圆满的果位——一乘之教即在理、行、果三重的完整结构中，以中道佛性为起点与归宿（[《大乘玄论》](https://cbetaonline.dila.edu.tw/T45n1853_003)，[《法华玄论》](https://cbetaonline.dila.edu.tw/T34n1720_003)，[中国佛学院·从《大乘玄论》看吉藏对佛性义的主张](http://www.zgfxy.cn/ztjj/zgfx/x/zdesjqeyn4/2013/05/07/1047471378.html)）。

从判教角度说，《涅槃》佛性教与《法华》一乘教在吉藏这里互为表里：《法华》明「一道一乘」，《涅槃》明「佛性常住」，而如前所引「只是一道，三义说之」，一乘与佛性本是同一中道的不同名目。《中观论疏》从反面对照大小乘：「**大乘明一切众生皆有佛性并皆成佛，小乘人不明一切众生皆有佛性。若尔，既无佛性，虽复修行终不成佛。**」——若无佛性，则修行失去内在根据，「虽复修行终不成佛」；佛性论因此不是可有可无的锦上添花，而是大乘菩萨道之所以成立的先决条件。三论宗以破为宗，但破到最后必须有所建立：所建立的正是这不可破坏的中道佛性，它是「破邪」之后「显正」的最终落点，也是大乘修行信心的理论基石（[《中观论疏》卷十](https://cbetaonline.dila.edu.tw/T42n1824_010)，[华文哲学百科](https://mephilosophy.ccu.edu.tw/entry.php?entry_name=%E6%BC%A2%E5%82%B3%E4%BD%9B%E6%95%99%E4%BD%9B%E6%80%A7%E6%80%9D%E6%83%B3)）。

### 5.2 对修行者的激励与伦理规导

《胜鬘宝窟》集中阐述了佛说佛性教的现实用意，可归纳为四条：**其一，「令众生知自身中有于佛性，发菩提心、修行成佛，故说佛性」**——了知自己本具佛性，修行成佛就不是遥不可及的奢望，而是自身潜能的显发，由此发起菩提心、勇悍精进；**其二，「又令众生知他心身中悉有佛性，不行杀等十恶业罪」**——了知一切众生同具佛性，则杀害、恼害众生即是违逆佛性，佛性论直接导出护生、慈悲的伦理规范；**其三，「又于众生不起二乘等见，既唯有佛性即无复二乘，故于众生不起二乘之见」**——佛性遍在意味着没有定性声闻、定性缘觉，一切「二乘」差别只是暂时的方便，故修行者不应自甘下劣、亦不应轻视他人为不能成佛之辈；**其四，「又欲说波若（般若），故说于佛性。波若即是中道智慧」**——说佛性的最终目的是导入般若：佛性即中道，而中道之智即是般若，佛性教与般若教首尾相衔（[《胜鬘宝窟》](https://cbetaonline.dila.edu.tw/T37n1744)，[中华佛学研究所学报](https://www.chibs.edu.tw/ch_html/chbs/16/chbs1601.pdf)）。

这一实践指向，与「佛性常住」的对治功能相呼应。《法华玄论》所谓「**如来之身所以常者，良由本有佛性，见佛性故所以为常，故〈纯陀品〉云：未见佛性名为无常，见佛性故常恒无变**」——「见佛性」是常与无常的分界线：未见佛性时，一切都在无常流转中，修行者容易陷入「修道难成」的怯弱与「断灭无果」的疑惧；一见佛性，则知成佛的根据现成不欠、常恒无变，信心由此坚固。吉藏临终作《死不怖论》，正是这一教义的躬行示范：若佛性法身「未曾常与无常」、生死涅槃本来不二，则死亡亦无可怖。佛性论由此完成了从义理到心性、从信解到临终关怀的全链条贯通。此外值得注意的是，吉藏的佛性遍在论甚至延伸至无情之物：「**若欲明有佛性者，不但众生有佛性，草木亦有佛性……以依正不二故，众生有佛性则草木有佛性。**」依报（环境）与正报（众生）不二，中道实相遍一切处，故草木瓦石亦不离佛性——这一后来由天台湛然「无情有性」大加发挥的命题，在吉藏处已见端绪，进一步强化了佛性论作为平等、慈悲与生态关怀之根据的实践潜能（[《法华玄论》卷三](https://cbetaonline.dila.edu.tw/T34n1720_003)，[《大乘玄论》卷三](https://cbetaonline.dila.edu.tw/T45n1853_003)，[唐君毅](https://www.diancang.xyz/rulizhexue/17358/330214.html)）。

## 结语

回到最初的问题：一位毕生弘扬「缘起性空」「无所得」的三论宗匠，何以同时肯认《涅槃经》「佛性常住」「佛性不空」之教？本报告依据吉藏原典给出的答案是：这在其思想体系内部本不构成矛盾，因为吉藏对「佛性」与「常住」都作了彻底的中观化重释。就破的一面看，他系统清洗了十一家实体化的佛性说——佛性不是众生、不是心识、不是阿梨耶识、不是趋乐避苦的本能，也不是凝固的空理；凡可指认、堕四句、偏一边者，皆非正因。就立的一面看，佛性是「非真非俗之中道」「不见空与不空的第一义空」「说境为智、说智为境」的境智不二之法，是「三菩提中道种子」。就「常住」的安顿看，佛性之常既非现常（本有）亦非当常（始有），而是「非本非始、亦非当现」、超出常与无常之对待的中道之常；「常住」说是对治「无常病」的方便药言，法身本身「未曾常与无常」。最终，通过「法身即中道实相」（真如、法性、实际、法界、法身五名一体）与「隐显随缘」（迷名隐名藏、悟名显法身，隐显并出于缘）的解释框架，佛性常住与缘起性空被证明是同一实相的两种随宜言说：空，是就对治自性执而说；常，是就对治断灭见而说；而实相本身，横绝百非、四句常寂，空与不空、常与无常，皆在其中双照双遣。这一理论在实践上为一乘教提供了本体论根据——「一乘者，乃是佛性之大宗」——并落实为修行者发菩提心（知己有佛性）、不造十恶（知他有佛性）、不起二乘之见（佛性平等遍在）、终入般若中观（说佛性为说般若）的完整道路。吉藏佛性论的深刻之处，不在于在空与有之间折衷调和，而在于把「佛性」彻底还原为「空」的别名，又把「空」充实为具足成佛功能与教化力量的「中道」——破邪与显正、遮诠与表诠、般若与涅槃，至此浑然一体。
