# 53岁、80 kg中国成年人的两周科学健康中式食谱

## 执行摘要

本报告面向一位53岁、体重160斤（约80 kg）的中国成年人。目前已知信息只有年龄和体重；性别、身高、日常活动水平、慢性病史、肾功能、血压、血糖、血脂、食物过敏/不耐受、是否有减重目标均未提供。因此，不能严谨地计算个人基础代谢率、BMI或精确总能量消耗，也不能仅凭“80 kg”判断是否超重。中国成人通常以 BMI 18.5–23.9 kg/m² 为正常范围、24.0–27.9 kg/m² 为超重、≥28 kg/m² 为肥胖；BMI 需要身高才能计算。[1]

本方案采用《中国居民膳食指南（2022）》和《中国居民膳食营养素参考摄入量（2023版）》的总体框架，并参考国家卫健委慢性病食养指导和 WHO 健康膳食建议。中国营养学会建议成年人每天有谷类、蔬果、奶类、大豆/坚果和适量鱼禽蛋肉，并做到每天至少12种、每周至少25种食物；其中谷类200–300 g、全谷物和杂豆50–150 g、薯类50–100 g，蔬菜至少300 g且深色蔬菜约占一半。[2] WHO同时强调膳食的充足、平衡、适量和多样性，成年人每天宜有至少400 g蔬果和25 g天然膳食纤维，总脂肪通常控制在总能量30%以内，并把食盐限制在5 g/天以内。[3]

在性别和活动量未知的情况下，50–64岁成年人参考能量大致可表示为：

| 活动水平 | 女性参考 | 男性参考 | 性别未知时的合理范围 |
| --- | --- | --- | --- |
| 久坐/轻体力活动 | 约1750 kcal/天 | 约2100 kcal/天 | 1750–2100 kcal/天 |
| 中等活动 | 约2050 kcal/天 | 约2450 kcal/天 | 2050–2450 kcal/天 |
| 较活跃/重体力活动 | 约2350 kcal/天 | 约2800 kcal/天 | 2350–2800 kcal/天 |

中国疾控相关膳食资料明确给出50–64岁轻身体活动男性约2100 kcal、女性约1750 kcal；公开转载的中国营养学会年龄—活动水平参考表给出上述中、高活动数值。因为缺乏身高、性别和真实活动记录，这些数值应理解为人群参考区间，而不是80 kg这个人的精确TDEE。[4]

据此，本报告把两周基础菜单设在约1900–1950 kcal/天，平均1921 kcal/天，相当于性别未知、低活动水平区间的中部。14天平均提供约蛋白质87 g、碳水化合物239 g、脂肪62 g、膳食纤维34 g/天；折算供能约为蛋白质18%、碳水化合物50%、脂肪29%。这个分布与国家卫健委成人肥胖食养资料中常用的碳水化合物50%–60%、蛋白质15%–20%、脂肪20%–30%的均衡减重膳食框架非常接近，但本报告并未假定此人肥胖或必须减重。[5]

最重要的个性化规则是：

- 若实际为女性、久坐且目标只是维持体重，可把本菜单每日减少约150–200 kcal；

- 若实际为男性且久坐，可视体重趋势每日增加约150–200 kcal；

- 中等活动者可在基础菜单上增加约300 kcal/天；

- 活跃者可增加约600 kcal/天；

- 如确有糖尿病、高血压、慢性肾病、痛风、心衰或严重食物过敏，应先按疾病重新调整，而不能直接照搬本菜单。国家卫健委已经分别制定高血压、糖尿病、慢性肾脏病等人群的专项食养指南。[6]

所有餐次热量和宏量营养素均为家庭烹饪条件下的估算值，不同品牌、鱼肉肥瘦、米饭含水量及实际用油会造成约±10%–15%的差异，因此本方案适合做日常规划，不应当当作临床代谢病房的精确称重膳食。

### 推荐的基础热量目标

建议先以1900–1950 kcal/天作为两周试行值，前提是没有特殊疾病且没有明确的高强度运动任务。原因不是“80 kg一定要减肥”，而是性别未知时，约1925 kcal恰好接近轻活动男女参考值的中点。

两周后应依据真实体重趋势、饥饿程度、运动表现及性别/身高重新校准：

| 实际情况 | 基础菜单调整 |
| --- | --- |
| 久坐女性，维持体重 | 每日减150–200 kcal，例如去掉坚果10–15 g，并将晚餐主食减约40–60 g熟重 |
| 久坐男性，维持体重 | 每日加150–200 kcal，例如增加一杯奶＋少量薯类 |
| 中等活动 | 加约250–350 kcal |
| 活跃/重体力 | 加约550–700 kcal |
| 明确超重且医生建议减重 | 按身高、BMI、腰围和实际活动量重新建立负能量平衡 |
| 偏瘦、近期非计划性掉体重 | 不应继续限能量，应增加主食、奶、坚果和蛋白质并查明原因 |

国家卫健委成人肥胖食养资料明确强调：减重膳食应依据个体基础代谢和身体活动量个性化安排，并保持宏量营养素平衡，不能用极端节食代替科学管理。[5]

## 菜谱做法与备餐流程

为了真正做到“简单易做”，14天并不需要学习56套不同菜谱。菜单采用模块化菜谱：主食模块＋蛋白质主菜＋蔬菜模块＋奶/水果/坚果。相同烹饪方法可以更换鱼种、绿叶菜和菌菇，从而减少备餐负担，同时维持食物多样性。

## 总体营养评估与个性化调整

### 两周营养达标情况

能量与宏量营养素

14天平均1921 kcal、蛋白质87.1 g、碳水239.2 g、脂肪61.6 g、膳食纤维33.9 g。蛋白质约占18.1%总能量、碳水约49.8%、脂肪约28.9%。

中国DRIs相关公开资料显示，18–64岁成人蛋白质推荐量通常约男性65 g/天、女性55 g/天；本菜单的87 g高于这一基础值，主要是因为安排了鱼、蛋、奶、豆和适量瘦肉，并考虑53岁以后维持肌肉量和饱腹感的实用需求。它仍只占约18%的总能量，并不属于极端高蛋白方案。[9]

但这是本方案最需要注意的医学例外：肾功能未提供。 如果有慢性肾脏病，本菜单不能直接按87 g蛋白质执行。国家卫健委已经发布慢性肾脏病专项食养指导，说明这类患者需要独立于普通成年人进行营养管理。[19]

膳食纤维平均约34 g/天，高于中国成年人25–30 g和WHO至少25 g的常用目标，来源包括燕麦、糙米、杂豆、荞麦、蔬果、菌菇、坚果等。[10] 初次从低纤维饮食切换到本方案的人，可以用一周逐步增加全谷物和豆类，并保证足够饮水，以降低腹胀不适。

钙

中国DRIs 2023公开解读给出的中国居民7岁以上一般钙推荐摄入量为800 mg/天。[20]

本菜单每天有约300 ml以上奶或酸奶，并反复使用豆腐、深绿叶菜、芝麻、小鱼虾等，因此在使用含钙凝固剂豆腐且奶量实际吃足的前提下，粗略估计多数日可达到约800–950 mg钙。由于不同豆腐凝固剂和牛奶品牌差异很大，这一微量营养素数值不应视为实验室级精算。

若不喝奶，应优先替换为：

无乳糖牛奶 → 无糖酸奶 → 明确标注钙强化的无糖豆奶/植物奶，同时继续保留豆腐和绿叶菜。单纯把牛奶换成普通、未强化的豆浆，通常不能保证提供等量钙。

铁

菜单通过瘦牛肉、瘦猪肉、鱼虾、鸡蛋、豆制品和绿叶菜提供铁；中国疾控也将红肉等列为较重要的膳食铁来源。[21] 从食物结构看，对多数无贫血成年人应较充足，但这里存在一个重要未知：53岁人的性别和女性是否仍有月经均未说明，这会明显影响铁需求。

因此不建议仅凭年龄自行服铁剂。有疲劳、苍白、既往缺铁、消化道出血风险或仍有较多月经失血者，应检查血常规和铁蛋白后再决定是否补铁。

维生素B12

鱼、虾、蛋、奶和肉类均是本菜单的重要B12来源。按常见食物成分估算，本食谱通常可达到约3–5 μg B12/天。作为国际对照，NIH成人B12推荐量为2.4 μg/天。[22]

因此，在不存在吸收障碍且按菜单正常吃动物性食品的情况下，B12不足的概率较低。纯素食者则不适用这一结论，需要通过B12强化食品或在专业指导下补充。

长期服用某些药物、胃肠手术史或吸收障碍也可能改变B12状况，因此“食物含量够”不等于每个人吸收一定足够。

维生素D

这是本计划中最可能仅凭食物难以稳定满足的营养素。中国DRIs 2023专家解读指出，维生素D是我国较常见的不足营养素之一，一个重要原因是天然富含维生素D的食物较少。[23]

本菜单每周安排三文鱼以及其他鱼类、蛋黄和奶制品，可以明显优于“完全不吃鱼蛋奶”的饮食，但粗略估计食物来源的维生素D大约只有4–8 μg/天、且日间波动很大。作为国际参考，NIH给19–70岁成人的推荐量为15 μg（600 IU）/天，并同样指出天然富含维生素D的食物数量有限。[24]

因此，53岁、尤其是很少户外活动、骨质疏松风险高或既往维生素D偏低的人，值得在体检时结合25-羟维生素D判断，而不是盲目长期大剂量服用补充剂。

其他微量营养素

蔬菜每天使用多个品种并大量采用深绿色蔬菜，可提供叶酸、维生素K、钾、镁、β-胡萝卜素等；鱼虾、鸡蛋、牛奶、肉类和大豆进一步增加锌、硒及多种B族维生素来源。WHO指出，跨食物组的多样化膳食有助于提高维生素和矿物质满足率。[15]

食盐应优先使用碘盐但总量仍不超过5 g/天，而不是通过多吃腌菜、咸鱼或大量海带来“补碘”。WHO建议成年人盐摄入低于5 g/天，并特别提醒酱油等调味料也是钠的重要来源。[15]

### 水分和调味

低身体活动成年人通常可把约1500–1700 ml/天饮水作为基础参考，再依据气温、出汗、运动及疾病情况增加；中国疾控和中国膳食指南相关资料均给出这一数量级。[21]

这个数值指饮水，不代表心衰、严重肾病等需要限液患者也应该照搬。若大量运动或高温出汗，需求会明显增加。

调味时应注意“盐不是只有盐罐里的盐”。酱油、蚝油、豆瓣酱、腐乳、咸菜、火腿、咸鱼、方便汤料和浓汤宝都会增加钠摄入。WHO明确建议通过减少盐和高钠调味料来控制总钠。[15]

### 高血压情况下如何改

高血压史：未指定。

若实际患高血压，菜单主体可以保留，但应进一步：

把盐控制到严格的<5 g/天范围，减少酱油、蚝油、咸菜、腌肉和外卖；蒸鱼用姜、葱、醋、柠檬、胡椒等代替大量蒸鱼豉油。WHO指出高钠摄入与血压升高相关，成年人盐应限制在5 g/天以内。[15]

蔬菜水果富含钾，通常有利于形成低钠、高质量的饮食结构；但肾功能下降或存在高钾血症者不能自行大量增加钾，也不要自行使用含氯化钾的低钠盐。WHO的低钠盐建议也明确要求识别高钾风险和肾病患者。[15]

### 糖尿病或血糖偏高情况下如何改

糖尿病/糖耐量异常：未指定。

若确有糖尿病，不需要把主食完全取消。国家卫健委“健康中国行动”明确建议糖尿病患者做到主食定量、因人而异，并优先选择低血糖生成指数食物，同时增加全谷物和杂豆的合理比例。[25]

在本菜单上可这样改：

早餐水果不要榨汁；米饭中的糙米、燕麦米、杂豆比例提高；白馒头必须换全麦或杂粮主食；香蕉、红薯、玉米等属于含碳水食物，应计入当餐总碳水，而不能在原主食之外无限增加。

更重要的是，若正在使用胰岛素或磺脲类等可能引起低血糖的药物，不能单纯按照本报告自行大幅减主食或随意取消加餐，需要结合药物剂量、餐前餐后血糖和运动进行个体调整。

### 慢性肾脏病情况下如何改

肾功能和CKD分期：未指定。

这是不应通过通用食谱自行“微调”的情况。国家卫健委已针对慢性肾脏病单独制定食养指南，意味着蛋白质、钠、钾、磷和水分需要结合疾病分期与化验结果管理。[19]

因此如果存在eGFR下降、蛋白尿、透析、高钾血症或高磷血症：

不要直接采用本方案87 g/天左右的蛋白质；不要自行改用钾盐；也不要因为“蔬菜健康”就无限增加高钾蔬果。

应由肾内科或临床营养师依据eGFR、尿蛋白、血钾、血磷和治疗方式重新设计菜单。

### 体重管理情况下如何改

减重意图：未指定。

首先应取得身高并计算BMI，而不是看到“160斤”就自动减肥。我国18岁以上成人BMI 24–27.9为超重、≥28为肥胖。[1]

若计算后确属超重或肥胖并希望减重，国家卫健委成人肥胖食养资料强调平衡膳食、总量控制和个体化能量负平衡，而不是戒掉碳水或长期采用极低热量饮食。[26]

本1900–1950 kcal方案是否已经形成热量赤字，完全取决于实际性别、身高和活动量。例如，对一名轻活动女性可能接近维持量甚至略高，而对一名体型较高、活动较多的男性则可能已经形成明显能量缺口。因此推荐根据连续2–4周晨起体重平均值和腰围趋势调整，而不是根据一天的体重变化改变饮食。

如需要小幅降低能量，优先顺序是：

先去含糖饮料、酒、油炸零食和额外油脂 → 再缩小精制主食份量 → 最后才考虑减少坚果或其他健康食物；不要首先削减蔬菜和优质蛋白质。

国家卫健委相关体重管理资料也强调减少高油、高糖、高盐食物、增加全谷物和蔬果并保持规律进餐。[27]

### 过敏和不耐受的替代

食物过敏/不耐受：未指定。

| 问题 | 直接替代方案 |
| --- | --- |
| 乳糖不耐受 | 普通奶→无乳糖奶、酸奶；也可选择明确钙强化的无糖豆奶 |
| 牛奶蛋白过敏 | 不使用任何牛奶/酸奶；改钙强化植物奶＋豆腐等 |
| 鱼虾过敏 | 鱼虾→去皮鸡肉、瘦肉、鸡蛋、豆腐；维生素D需另评估 |
| 鸡蛋过敏 | 蛋→豆腐、鱼肉、鸡胸；早餐增加豆浆/酸奶 |
| 大豆过敏 | 豆腐、豆浆、香干→蛋、奶、鱼、禽肉 |
| 坚果过敏 | 坚果→少量芝麻/种子，若种子亦过敏则从植物油和鱼获取不饱和脂肪 |
| 麸质相关疾病 | 全麦馒头/面包→米、玉米、小米、荞麦、红薯；需同时避免含麸质酱料交叉污染 |

### 综合判断

| 指标 | 两周方案评价 |
| --- | --- |
| 能量 | 条件性达标：约1921 kcal/天适合作为性别、活动未知时的中间起点，不能作为所有53岁80 kg成人的固定需求 |
| 蛋白质 | 充足：约87 g/天；肾功能正常者通常足够，CKD需重新设计 |
| 碳水 | 合理：约50%能量，且大量来自全谷物、杂豆和薯类 |
| 脂肪 | 合理：约29%能量，接近WHO≤30%的总体方向 [15] |
| 膳食纤维 | 充足：约34 g/天，高于25–30 g目标 [10] |
| 钙 | 大多数日有望满足：关键是实际喝足奶并选择含钙豆腐；中国一般成人参考800 mg/天 [20] |
| 铁 | 大多数无贫血成年人预计充足；性别、月经状态和贫血史未知，因此不能做个体诊断 |
| 维生素B12 | 预计充足：鱼、蛋、奶、肉持续供应；成人国际参考2.4 μg/天 [28] |
| 维生素D | 最值得关注：鱼和蛋有所贡献，但单靠食物未必稳定充足；中国DRIs专家也指出维生素D不足较常见 [23] |
| 钠 | 可达标但取决于厨师：盐、酱油、腌菜和加工食品合计必须控制；WHO盐<5 g/天 [15] |
| 食物多样性 | 良好：两周覆盖多类谷物、薯类、豆类、奶、蛋、鱼虾、禽畜肉、菌菇和多色蔬果，符合中国膳食指南多样化原则 [11] |

最终结论：在“53岁、80 kg，但性别、身高、活动水平和疾病史全部未知”的条件下，这份约1900–1950 kcal/天的两周菜单是一个合理的健康普通膳食模板，其优势是全谷物和蔬菜比例高、蛋白质来源分散到鱼禽蛋奶豆、膳食纤维充足、烹饪方法简单且少油，并把高盐高糖加工食品降到很低。依据现有估算，宏量营养素整体平衡，钙、铁和B12的食物来源较充足；维生素D是最可能仍需通过日照状况、强化食品或化验结果进一步评估的营养素。[29]

同时，80 kg本身不是减重指征。获得身高、性别、腰围、平均每日步数/运动量、血压、空腹血糖或HbA1c、血脂、肌酐/eGFR、过敏史后，才能把这份“科学通用版”进一步转换为真正的个体化营养处方。国家卫健委和中国DRIs均强调营养需要受到年龄、性别、身体状态、活动和疾病情况影响。[30]
