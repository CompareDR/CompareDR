# 系统性金融风险研究综述：理论基础与微观结构

本文将文献边界严格限定在**截至2020年2月底已经形成的理论与研究**。从研究层次看，可以把系统性金融风险文献理解为两个相互衔接的问题：第一，金融体系中的脆弱性为什么会形成、为什么会把普通冲击放大为宏观波动；第二，一旦局部机构或市场出现压力，这种压力又如何借助资产负债表联系、交易结构和价格机制扩散到整个金融体系。前一问题对应金融加速器和明斯基的金融不稳定性假说，后一问题则对应金融网络、流动性螺旋与金融传染研究。[[1]](https://www.nber.org/papers/w6455)

一个重要的概念界定是：**金融加速器并非狭义意义上专门研究“银行之间如何传染”的系统性风险模型**，它首先是一种宏观金融放大机制；而金融网络、清算网络和火售模型才更直接研究冲击如何从一个资产负债表传到另一个资产负债表。因此，二者并不是替代关系，而分别回答系统性风险的“生成与放大”和“横向传播”问题。[[2]](https://www.sciencedirect.com/science/chapter/handbook/pii/S157400489910034X)

## 理论基础对比

### 金融加速器：DSGE中的信用摩擦与冲击放大

现代“金融加速器”（financial accelerator）的理论脉络通常追溯到 **Ben Bernanke 与 Mark Gertler** 关于代理成本、企业净值和经济波动的研究，尤其是 Bernanke 与 Gertler（1989）的 *Agency Costs, Net Worth, and Business Fluctuations*；其成为可用于定量宏观分析的经典DSGE框架，则主要归功于 **Bernanke、Gertler 与 Simon Gilchrist（BGG）** 的 *The Financial Accelerator in a Quantitative Business Cycle Framework*。BGG明确以动态一般均衡模型考察信用市场摩擦如何改变商业周期的振幅和持续性。[[3]](https://www.nber.org/papers/w2015)

**核心逻辑是“资产负债表决定融资成本，而融资成本反过来改变资产负债表”。** 在存在借贷双方信息不对称和代理问题时，外部资金不像企业内部留存资金那样便宜。Bernanke将二者之间的成本差额称为**外部融资溢价（external finance premium）**：债权人需要筛选、监督借款人，并承担违约和激励问题，由此使外部融资存在额外成本。借款人的净值、流动资产和现金流越充足，它越有能力承担项目风险，债权人的代理问题越轻，外部融资溢价通常也越低；反之，净值下降会提高融资溢价。[[4]](https://www.federalreserve.gov/newsevents/speech/bernanke20070615a.htm)

因此，可以把BGG式机制概括为：

**负向宏观冲击 → 企业利润和资产价格下降 → 借款人净值下降 → 外部融资溢价上升、可获得信贷减少 → 投资和支出下降 → 总产出与资产价格进一步下降 → 净值再次恶化。** [[5]](https://www.federalreserve.gov/newsevents/speech/bernanke20070615a.htm)

这里的关键并非单纯“银行少放了一笔贷款”，而是存在一个**反馈回路**。初始冲击可能很小，甚至本身并不持久，但是它改变了借款人的资产负债表，从而改变下一期的融资条件；融资条件又影响投资、生产和资产价格。因此，金融市场的不完全性能够同时提高冲击的**振幅**和**持续性**。Bernanke后来回顾这套理论时特别强调，Bernanke–Gertler模型可以在初始实际冲击并不持久的情况下产生较持久的经济波动。[[6]](https://www.federalreserve.gov/newsevents/speech/bernanke20070615a.htm)

从假设上看，经典金融加速器属于**一般均衡—最优化**的建模传统：家庭、企业和金融契约被放在一个动态均衡体系中，金融摩擦以代理成本、信息不对称或类似契约摩擦进入模型；宏观冲击改变借款人净值，再通过融资溢价进入投资和总需求。需要特别区分的是，**价格黏性并不是“金融加速器”这一机制本身的定义条件**；后来的货币DSGE应用常把金融加速器与名义摩擦结合起来，以分析货币政策、资产负债表和实际经济之间的互动。[[7]](https://www.sciencedirect.com/science/chapter/handbook/pii/S157400489910034X)

从系统性风险角度看，这套理论最有价值的地方在于解释了为什么金融体系会产生**顺周期性**。景气阶段资产价格和净值较高，外部融资溢价较低，融资和投资容易扩大；衰退阶段则相反。也就是说，金融部门不是被动地“记录”实体经济冲击，而会使资产负债表变化产生第二轮宏观效应。[[5]](https://www.federalreserve.gov/newsevents/speech/bernanke20070615a.htm)

不过，把DSGE传统简单描述成“只能研究外生冲击”也并不准确。到全球金融危机之后，均衡宏观金融模型开始显著强化金融部门自身的非线性。例如 **Markus Brunnermeier 与 Yuliy Sannikov（2014）** 的 *A Macroeconomic Model with a Financial Sector* 表明，即使外生风险很低，金融中介的杠杆和财富分布也能使体系产生显著的**内生风险和非线性放大**；经济在正常区域和危机区域之间的动态并非简单的线性偏离。这说明后来的宏观金融理论实际上部分缩小了早期DSGE与明斯基思想之间的距离。[[8]](https://www.aeaweb.org/articles?id=10.1257%2Faer.104.2.379)

### 明斯基金融不稳定性假说：稳定如何孕育不稳定

与BGG不同，**Hyman P. Minsky 的 Financial Instability Hypothesis（FIH，金融不稳定性假说）把不稳定性本身放在金融资本主义的内部动态中解释**。Minsky在1992年的 *The Financial Instability Hypothesis* 中明确反对把复杂金融经济视为天然趋向稳定均衡的体系；他认为，在拥有复杂金融结构、资本资产和债务契约的经济中，金融关系本身可能具有“偏离放大”（deviation-amplifying）的性质。更关键的是，FIH**并不需要一个外生冲击作为商业周期和危机的根本起点**。[[9]](https://www.levyinstitute.org/publications/the-financial-instability-hypothesis)

明斯基理论的起点不是一个静态的“负债率”，而是企业未来现金流与现有债务支付承诺之间的关系。他由此提出著名的三种融资状态。[[10]](https://www.levyinstitute.org/wp-content/uploads/2024/02/wp74.pdf)

**Hedge finance（对冲型/稳健型融资）**是指经营现金流足以履行债务合同中的利息和本金支付；债务人原则上不依赖持续再融资来维持既有债务。**Speculative finance（投机型融资）**中，现金流可以支付利息等收入账户上的债务义务，却不足以偿还本金，因此必须滚动融资或重新发行负债。**Ponzi finance（庞氏型融资）**则进一步恶化：经营现金流甚至不足以支付全部利息和本金，只能通过增加借款、资本化利息或出售资产维持头寸。明斯基认为，一个经济体系中投机型和庞氏型融资所占比例越高，其金融结构就越容易表现为偏离放大型。[[11]](https://www.levyinstitute.org/wp-content/uploads/2024/02/wp74.pdf)

FIH最关键的命题因而可以压缩为一句话：**稳定会改变人的融资行为，从而孕育下一阶段的不稳定。** 明斯基提出，在持续繁荣期间，原本以hedge finance为主、相对稳定的金融结构会逐渐向speculative甚至Ponzi finance移动。原因不是突然出现一个外来的“大冲击”，而是长期成功本身会改变债务结构、融资方式和对未来现金流的判断；与此同时，银行等金融机构也是追求利润的创新者，会创造新的融资方式，而不是机械地按固定信贷规则供给货币。[[12]](https://www.levyinstitute.org/wp-content/uploads/2024/02/wp74.pdf)

于是，明斯基式危机的典型演化过程可以写成：

**持续繁荣 → 债务承诺增加、安全边际下降 → hedge融资向speculative/Ponzi融资迁移 → 对滚动融资和资产价格越来越依赖 → 利率上升、融资条件收紧或实际现金流不及预期 → 部分头寸无法再融资 → 被迫出售资产 → 资产价格下降、净值恶化 → 更多机构需要出售资产和缩减投资 → 金融压力进入实体经济。** [[13]](https://www.levyinstitute.org/wp-content/uploads/2024/02/wp74.pdf)

因此，明斯基理论中的金融体系不只是**冲击放大器**，而可能是**脆弱性生成器**。在繁荣时期，私人部门看似越来越安全，因为违约较少、资产价格上涨、利润充足；然而正是这些成功经验使融资结构逐渐依赖更高杠杆和更频繁的再融资。一旦融资条件改变，过去稳定时期建立起来的资产负债表就可能同时变成危机传播机制。[[9]](https://www.levyinstitute.org/publications/the-financial-instability-hypothesis)

这里也解释了FIH为什么与纯粹“外生冲击—均衡回归”故事存在根本区别。在明斯基那里，繁荣并不只是使经济暂时偏离一个恒定的稳态；繁荣本身会**改变金融结构**。换句话说，系统的抗冲击能力不是固定参数，而是商业周期历史的结果。Minsky明确提出两项基本判断：某些融资制度可以是稳定的，另一些则是不稳定的；而经过长期繁荣，经济会从前者向后者演化。[[14]](https://www.levyinstitute.org/wp-content/uploads/2024/02/wp74.pdf)

### 核心分歧、互补与系统性风险含义

将二者放在一起比较，最重要的不是笼统地说“一个主流、一个非主流”，而是看它们究竟把**金融不稳定的因果起点**放在哪里。

| 比较维度 | BGG式金融加速器 | Minsky FIH |
|---|---|---|
| **核心问题** | 为什么信用摩擦使宏观冲击变得更大、更持久。[[15]](https://www.nber.org/papers/w6455) | 为什么正常繁荣过程会内生地产生越来越脆弱的金融结构。[[9]](https://www.levyinstitute.org/publications/the-financial-instability-hypothesis) |
| **关键金融变量** | 借款人净值、资产价值、外部融资溢价、信贷条件。[[6]](https://www.federalreserve.gov/newsevents/speech/bernanke20070615a.htm) | 现金流与债务承诺的匹配、再融资依赖、安全边际，以及hedge/speculative/Ponzi结构。[[13]](https://www.levyinstitute.org/wp-content/uploads/2024/02/wp74.pdf) |
| **主要摩擦/机制** | 信息不对称和代理成本导致外部融资比内部融资昂贵；净值下降使融资条件进一步恶化。[[16]](https://www.sciencedirect.com/science/chapter/handbook/pii/S157400489910034X) | 债务融资结构随繁荣演变，投机性和庞氏融资比重提高，使体系本身从稳定走向不稳定。[[17]](https://www.levyinstitute.org/wp-content/uploads/2024/02/wp74.pdf) |
| **风险的起点** | 经典表达通常从宏观或金融冲击出发，重点研究冲击如何被金融摩擦放大。[[18]](https://www.nber.org/papers/w6455) | 不要求危机必须由外生冲击启动；体系内部的金融演化足以造成周期和脆弱性。[[9]](https://www.levyinstitute.org/publications/the-financial-instability-hypothesis) |
| **金融部门的作用** | 主要是**amplifier / propagation mechanism**：放大并延长波动。[[6]](https://www.federalreserve.gov/newsevents/speech/bernanke20070615a.htm) | 既是放大器，又是**generator of fragility**：稳定时期本身创造未来的不稳定。[[14]](https://www.levyinstitute.org/wp-content/uploads/2024/02/wp74.pdf) |
| **对实体经济的反馈** | 净值下降 → 融资溢价上升 → 投资、支出和产出下降。[[5]](https://www.federalreserve.gov/newsevents/speech/bernanke20070615a.htm) | 再融资困难、资产火售和金融头寸恶化 → 投资和利润下降 → 债务更难得到现金流验证。[[9]](https://www.levyinstitute.org/publications/the-financial-instability-hypothesis) |
| **危机动态** | 经典模型强调连续的资产负债表反馈；后来的宏观金融模型进一步产生强非线性和内生风险。[[8]](https://www.aeaweb.org/articles?id=10.1257%2Faer.104.2.379) | 从hedge向speculative/Ponzi的状态迁移本身使体系进入非线性脆弱区域。[[13]](https://www.levyinstitute.org/wp-content/uploads/2024/02/wp74.pdf) |

因此，二者实际上具有很强的**互补性**。金融加速器非常适合回答“给定一个冲击以及一组金融摩擦，为什么最终的产出和投资反应会远大于初始冲击”；FIH则更适合回答“为什么在没有明显坏消息的长期繁荣中，经济会主动积累使未来冲击更危险的杠杆、期限错配和再融资依赖”。前者尤其擅长形式化、一般均衡和定量研究；后者则把研究注意力放到金融制度、债务结构的历史演化和**内生脆弱性**上。[[19]](https://www.sciencedirect.com/science/chapter/handbook/pii/S157400489910034X)

如果用现代系统性风险语言重新表达，两者的差异可以进一步概括为：BGG重点刻画**shock amplification（冲击放大）**，Minsky重点刻画**vulnerability accumulation（脆弱性积累）**。而2008年以后以 Brunnermeier–Sannikov 等为代表的均衡宏观金融研究逐步把内生杠杆、金融中介净值和非线性危机区间纳入正式模型，因此“DSGE一定外生、Minsky一定内生”的绝对二分到2010年代已经不再成立；真正持续存在的分歧，是如何理解均衡、金融结构的内生演化以及危机状态的形成。[[20]](https://www.aeaweb.org/articles?id=10.1257%2Faer.104.2.379)

## 微观结构研究

### 金融网络：复杂性、“稳健但脆弱”与核心—边缘

微观层面的第一个重要转向，是不再只看一家银行的资产负债表是否稳健，而是研究**银行之间的资产负债表连接结构**。在网络模型中，一家银行的负债往往是另一家银行的资产，因此个体层面的风险管理行为可能产生系统层面的外部性；决定稳定性的并非简单的“连接越多越危险”或“越分散越安全”，而是**网络密度、集中度、连接对象以及冲击规模之间的交互作用**。[[21]](https://www.journals.uchicago.edu/doi/abs/10.1086/262109)

这一研究传统的经典起点之一是 **Franklin Allen 与 Douglas Gale（2000），*Financial Contagion***。他们研究银行通过跨地区债权安排相互保险流动性冲击的体系，并发现网络连接既可能承担**风险分担**功能，也可能成为**传染**通道。在他们的模型中，更完整的跨银行债权结构可以比不完整的结构更有韧性，这第一次非常清楚地揭示了金融互联关系的“双刃剑”特征。[[22]](https://www.journals.uchicago.edu/doi/abs/10.1086/262109)

另一个奠基性框架是 **Larry Eisenberg 与 Thomas Noe（2001），*Systemic Risk in Financial Systems***。他们把金融机构表示为相互持有债务索取权的网络，在有限责任和债务优先规则下求解所有机构能够同时实现的**清算支付向量（clearing payment vector）**，并证明在适当条件下清算解的存在性和唯一性。这个框架使研究者能够严格讨论：一家机构少支付一美元，怎样改变其他机构资产价值和支付能力，并最终形成违约级联。[[23]](https://pubsonline.informs.org/doi/10.1287/mnsc.47.2.236.9835)

网络理论随后得到一个非常重要的结论：**金融系统可能同时表现为“robust-yet-fragile（稳健但脆弱）”。** Paul Gai 与 Sujit Kapadia（2010）的网络传染模型指出，网络互联和风险分散可能使传染发生的概率较低，因此系统对大量普通、小规模冲击显得相当稳健；但是**一旦传染真正启动，其条件性后果可能非常广泛**。所以“稳健但脆弱”准确的含义并不是简单的“平时安全、危机时危险”，而是：

> **系统可以具有较低的传染发生概率，同时具有很高的“给定传染已经发生之后”的系统损失。** [[24]](https://www.bankofengland.co.uk/working-paper/2010/contagion-in-financial-networks)

这与“分散化总是降低风险”的直觉形成直接冲突。**Daron Acemoglu、Asuman Ozdaglar 与 Alireza Tahbaz-Salehi（2015）**进一步证明了网络稳健性存在类似**相变（phase transition）**的特征：当负向冲击较小时，更密集、更分散的银行间负债网络有利于把损失分散开，从而提高稳定性；但冲击超过一定范围以后，同一组密集连接反而提供了更多传播路径，使系统更容易发生广泛失败。[[25]](https://www.aeaweb.org/articles?id=10.1257%2Faer.20130456)

**Matthew Elliott、Benjamin Golub 与 Matthew Jackson（2014）**得到的结论也强调这种非单调性。他们区分金融网络的“integration”和“diversification”，指出增加分散化在初始阶段可能把原本互不相关的机构连接成一个可以发生级联的体系，但进一步分散又能够降低个别暴露带来的风险。因此，在系统性风险研究中，**连接数本身通常不是充分统计量；连接的结构和敞口分布才是真正关键的对象**。[[26]](https://www.aeaweb.org/articles?id=10.1257%2Faer.104.10.3115)

这就自然引出用户特别关心的**核心—边缘（core-periphery）结构**。**Ben Craig 与 Goetz von Peter（2010）**在德国银行间市场数据中发现明显的分层现象，并构建了核心—边缘网络模型：少数“money-center”或核心银行承担大量银行间中介活动，而外围机构主要借助核心机构完成资金流动。其研究利用约1,800家银行的数据发现了很强的核心—边缘结构证据。[[27]](https://www.bis.org/publ/work322.htm)

典型的核心—边缘网络可以理解为：**核心银行彼此之间高度连接，同时连接大量外围银行；外围银行主要连接核心，而外围机构之间直接连接较少。** 这种结构在正常时期可以降低搜寻和交易成本，使核心机构高效完成流动性再分配；但其系统风险含义是，风险可能集中到数量很少的中介节点，因此核心节点受到严重冲击时，影响往往与普通外围节点不同。后一点应当理解为由核心—边缘结构事实与网络传播模型共同推导出的系统性含义，而不是“所有核心—边缘网络必然不稳定”的普遍定理。[[28]](https://www.rba.gov.au/publications/rdp/2018/2018-01/full.html)

因此，截至2020年初，金融网络研究已经形成一个相当明确的结论：**系统稳定性与网络复杂性之间一般不是单调关系。** 更多连接能够提供风险分担和保险，但也创造更多潜在传播路径；适度分散可能增强韧性，大规模冲击下同一网络却可能加速级联；而核心—边缘结构则进一步把“谁连接谁”与“谁具有系统重要性”纳入分析。Allen–Gale（2000）、Eisenberg–Noe（2001）、Gai–Kapadia（2010）、Elliott–Golub–Jackson（2014）和 Acemoglu–Ozdaglar–Tahbaz-Salehi（2015）构成这一脉络中非常有代表性的理论节点。[[29]](https://www.journals.uchicago.edu/doi/abs/10.1086/262109)

### 市场流动性：融资约束与“流动性螺旋”

微观结构研究的第二条主线，是把系统风险从“银行会不会资不抵债”扩展到**市场还能不能正常交易、金融机构还能不能获得融资**。这一领域最重要的理论之一是 **Markus Brunnermeier 与 Lasse Heje Pedersen（2009），*Market Liquidity and Funding Liquidity***。他们把两类在传统研究中往往分开的流动性放进同一个模型：**市场流动性（market liquidity）**指资产能够多容易地被交易，而**融资流动性（funding liquidity）**则指交易者多容易获得资金以维持和扩展头寸。[[30]](https://markus.scholar.princeton.edu/publications/market-liquidity-and-funding-liquidity)

二者具有天然的双向依赖关系。一方面，证券市场中的经纪商、套利者和做市商只有在能够获得资金、满足保证金要求时，才能购买暂时被低估的资产并提供市场流动性；因此融资条件变差会使他们缩减头寸。另一方面，融资方愿意提供多少杠杆、要求多高的保证金，又取决于头寸本身的波动性和市场流动性。资产越难卖、价格越容易剧烈波动，债权人就越可能提高保证金，从而进一步降低交易者的融资能力。[[31]](https://markus.scholar.princeton.edu/publications/market-liquidity-and-funding-liquidity)

于是形成经典的**liquidity spiral（流动性螺旋）**：

**初始亏损或融资冲击 → 可用资本下降/融资约束收紧 → 做市商、套利者缩减头寸 → 市场深度降低、卖压增加 → 资产价格进一步偏离基本价值 → 更多按市值计价亏损和更高波动 → 保证金要求进一步上升 → 再次去杠杆。** [[32]](https://markus.scholar.princeton.edu/document/98)

Brunnermeier 与 Pedersen进一步把这一反馈拆成两个相互加强的子螺旋。第一是**margin spiral（保证金螺旋）**：融资压力导致市场流动性降低，低流动性使融资方提高保证金；保证金上升进一步压缩可用于建立头寸的资金，交易者不得不进一步去杠杆，于是市场更加缺乏流动性。[[33]](https://markus.scholar.princeton.edu/document/98)

第二是**loss spiral（亏损螺旋）**：融资受约束的机构抛售资产，使价格下降；持有相同或类似资产的机构出现账面亏损，净值进一步减少；为了满足资本和融资约束，它们也不得不卖出资产，由此造成更大的价格下降。两个螺旋并非互相独立，而是会彼此强化，因此整体冲击可以明显超过单独一种反馈的效果。[[32]](https://markus.scholar.princeton.edu/document/98)

这一机制与 **Rodrigo Cifuentes、Gianluigi Ferrucci 与 Hyun Song Shin（2005）** 关于资产火售（fire sales）的研究高度互补。他们把金融机构之间的资产负债表联系、偿付能力约束、按市值计价和缺乏流动性的资产市场放入同一个框架，发现受压机构出售资产会压低价格，而价格下降又通过按市值计价恶化其他机构的资产负债表，迫使其进一步出售资产；因此即使机构之间并没有特别大的直接双边债权，也可能通过**市场价格这一共同状态变量**发生系统性传染。[[34]](https://www.bankofengland.co.uk/working-paper/2005/liquidity-risk-and-contagion)

这也是流动性理论对系统性风险研究的一个关键贡献：它说明**“有偿付能力”和“不会引发系统风险”并不是一回事**。当大量金融机构同时依靠短期融资、相似的保证金规则和相似的风险管理约束时，一家机构为了自救而进行的资产出售，对个体而言可能完全理性，却会压低所有机构共同面对的市场价格。这种**价格外部性**可以把融资流动性问题变成市场流动性问题，再把市场流动性问题反馈成新的融资问题。[[35]](https://www.bankofengland.co.uk/working-paper/2005/liquidity-risk-and-contagion)

把它与前面的金融加速器联系起来，可以看到二者都是资产负债表反馈机制，但作用层级不同：BGG主要强调**借款人净值—融资成本—实体投资**的反馈；Brunnermeier–Pedersen则强调**金融交易者资金约束—市场流动性—价格—保证金**的反馈。前者更直接连接金融条件与宏观产出，后者更细致地揭示金融市场内部为什么能够在短时间内出现剧烈的非线性去杠杆。[[36]](https://www.federalreserve.gov/newsevents/speech/bernanke20070615a.htm)

### 金融传染：直接与间接渠道

截至2020年初，一个很有用、也最能统一不同文献的分类，是把金融传染区分为**直接传染（direct contagion）**和**间接传染（indirect contagion）**。欧洲系统性风险委员会（ESRB）对此给出了清楚的区分：直接传染建立在金融机构之间的合同义务和直接敞口之上；间接传染即使在机构之间没有直接合同联系时也能够发生，并可进一步通过市场价格和信息等机制传播。[[37]](https://www.esrb.europa.eu/pub/series/occasional-papers/html/index.bg.html)

**直接传染的核心是“你的违约直接使我的资产减少”。** 银行间贷款、存款和支付义务，以及抵押融资或衍生品等合同，都可能形成这种双边资产负债表联系。若机构A违约，它原本承诺给机构B的支付无法完全实现，于是B遭受资产损失；如果B的资本缓冲也较薄，它又可能无法足额履行对C的义务，由此形成所谓的**default cascade / domino effect（违约级联或多米诺效应）**。Allen–Gale（2000）研究的银行间索取权传染，以及 Eisenberg–Noe（2001）的清算网络，都属于这一理论传统。[[38]](https://www.journals.uchicago.edu/doi/abs/10.1086/262109)

直接传染机制有一个非常明确的网络含义：关键变量包括双边敞口规模、资本缓冲、债务优先关系和网络拓扑。如果一个银行发生损失，但其债权人有足够资本吸收，这条传染链就会停止；反之，当多个节点资本较薄或者重要机构处于网络枢纽位置时，同样大小的初始损失可能穿透多个资产负债表。[[39]](https://pubsonline.informs.org/doi/10.1287/mnsc.47.2.236.9835)

**间接传染则不同：机构A并不需要欠机构B的钱，A仍然能够使B遭受损失。** ESRB把这一问题特别归纳为市场价格渠道以及信息溢出渠道；而相关资产火售、流动性和投资组合再平衡文献又进一步展示了这种间接联系的具体微观机制。[[40]](https://www.esrb.europa.eu/pub/series/occasional-papers/html/index.bg.html)

最典型的是**共同资产持有—火售渠道**。假设银行A由于自身亏损必须出售某种资产；如果市场深度有限，A的出售行为会压低该资产的市场价格。银行B虽然没有向A贷款，却恰好也持有同一资产，那么按市值计价后B就产生损失；如果B因此触及资本或杠杆约束，也开始卖出，价格就进一步下降。这是 Cifuentes–Ferrucci–Shin（2005）模型的核心机制之一，也是后来“overlapping portfolios（重叠投资组合）”研究的重要基础。[[34]](https://www.bankofengland.co.uk/working-paper/2005/liquidity-risk-and-contagion)

另一种是**融资与流动性渠道**。一家大型机构削减杠杆、囤积流动性或者被迫出售资产，可以提高市场波动和保证金，从而使其他原本没有直接敞口的机构也遭遇融资压力；Brunnermeier–Pedersen（2009）的流动性螺旋正好说明了这种冲击为什么具有系统性：融资流动性和市场流动性共同恶化，会使去杠杆行为彼此强化。[[41]](https://markus.scholar.princeton.edu/publications/market-liquidity-and-funding-liquidity)

第三种间接机制是**投资组合再平衡和信息渠道**。**Laura Kodres 与 Matthew Pritsker（2002）**在 *A Rational Expectations Model of Financial Contagion* 中表明，一个市场中的特异性冲击可以通过跨市场投资组合调整改变投资者对其他共同宏观风险的暴露，从而把压力传到其他资产或市场；其模型说明，即使第二个市场并没有出现相应的基本面新闻，也可能观察到类似“传染”的价格反应。[[42]](https://onlinelibrary.wiley.com/doi/abs/10.1111/1540-6261.00441)

信息传染则进一步意味着，某家银行或某类资产出现坏消息后，投资者可能重新评估其他看似类似的金融机构，尤其当资产质量不透明时。这种情况下，机构之间甚至既不需要存在直接贷款，也不一定需要持有完全相同的资产；信息不对称本身即可使一处发生的坏消息改变其他市场参与者的估值和融资行为。ESRB因此把信息溢出视为间接传染的重要组成部分。[[37]](https://www.esrb.europa.eu/pub/series/occasional-papers/html/index.bg.html)

这里有一个研究上非常重要的识别问题：**“共同冲击”本身不应自动等同于“传染”。** 如果两家银行都持有石油资产，而一个完全外生的油价冲击同时使两家银行亏损，这首先是共同风险暴露；更严格意义上的传染要求存在第二轮传播机制——例如A因为亏损而抛售资产，A的行动进一步压低B的资产价格，或者A的失败产生关于B的新信息。这样区分，才能把真正的内生系统传播与简单的同步基本面冲击分开。这一界定与ESRB关于直接合同传播和无直接合同的市场价格/信息传播的分类是一致的。[[43]](https://www.esrb.europa.eu/pub/series/occasional-papers/html/index.bg.html)

由此可以把截至2020年初的微观系统性风险文献压缩成一个统一链条：

**个体冲击或损失  
→ 直接资产负债表联系（Allen–Gale；Eisenberg–Noe）  
和/或  
→ 去杠杆与资产火售（Cifuentes–Ferrucci–Shin）  
→ 市场流动性下降、保证金上升（Brunnermeier–Pedersen）  
→ 更多机构亏损和融资受限  
→ 网络中的核心节点与高暴露机构受到冲击  
→ 直接违约与间接价格传染相互强化  
→ 局部金融压力转变为系统性事件。** [[44]](https://www.journals.uchicago.edu/doi/abs/10.1086/262109)

从整个研究脉络看，宏观理论与微观结构理论实际上可以拼接为一个较完整的系统性风险框架。**金融加速器**解释资产负债表恶化为什么能够放大冲击并影响投资和产出；**Minsky FIH**解释为什么长期稳定本身会内生积累杠杆、再融资依赖和脆弱性；**金融网络**决定损失沿哪些机构关系传播以及为何连接具有“稳健但脆弱”的双重性质；**流动性螺旋**解释为什么市场价格和融资条件能够形成快速的正反馈；而**传染理论**则把这些机制进一步区分为合同敞口驱动的直接传染，以及价格、流动性、投资组合和信息驱动的间接传染。[[45]](https://www.nber.org/papers/w6455)

因此，对系统性金融风险最有解释力的理解不是寻找单一“危机原因”，而是同时考察两个维度：**时间维度上的脆弱性积累和资产负债表放大，以及横截面维度上的网络、流动性和市场传染。** 在这一框架下，Bernanke–Gertler–Gilchrist 与 Minsky回答的是“为什么体系会变得容易受到冲击、为什么金融会放大实体波动”；Allen–Gale、Eisenberg–Noe、Gai–Kapadia 和 Acemoglu 等回答“冲击怎样穿越金融网络”；Cifuentes–Ferrucci–Shin 与 Brunnermeier–Pedersen回答“为什么共同资产和融资约束能在没有直接违约联系时制造系统反馈”；Kodres–Pritsker等则补充了跨市场投资组合与信息传播机制。这些文献共同构成了截至2020年3月以前研究系统性金融风险最重要的理论基础之一。[[46]](https://www.sciencedirect.com/science/chapter/handbook/pii/S157400489910034X)
