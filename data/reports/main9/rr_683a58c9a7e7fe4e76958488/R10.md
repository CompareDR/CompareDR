# Sparse Engram Predictive Coding Network: A Biologically Plausible Classifier that Integrates Engrams and Predictive Coding

## 1. Design Rationale

Engrams and predictive coding (PC) are typically studied in separate literatures. Engrams—the sparse, reactivatable neuronal ensembles that store a specific memory [1]—are usually placed in hippocampus and amygdala. Predictive coding—the hierarchical architecture in which top-down predictions are compared with bottom-up sensory signals and only the residual error is propagated [2]—is usually placed in neocortex. A model that genuinely integrates them must do more than wire a Hopfield-style memory module to a PC inference engine; it must identify the place in the PC hierarchy where a stable, sparse, excitability-allocated ensemble becomes the *generative prior* over categories, and show that the PC dynamics themselves are what recruit and re-shape that ensemble.

The proposed Sparse Engram Predictive Coding Network (SEPCN) makes the following architectural commitment: the *top layer* of a standard PC hierarchy is a sparse, k-winner-take-all (k-WTA) population of "category engram" cells. Each category engram cell is recruited by an excitability-dependent allocation rule (a CREB-like mechanism) when its input pattern wins the k-WTA competition during inference. The cell then persists as the long-term memory trace for that category. Classification becomes a competition: given a new input, the PC dynamics settle into a state in which exactly one engram cluster dominates the top layer, and that cluster is the predicted class.

This is, formally, a continuous Modern Hopfield network embedded as the top layer of a PC hierarchy. The Modern Hopfield update `x_new = X · softmax(β Xᵀx)` [3] is mathematically equivalent to the softmax-attention read-out of an associative memory; the PC dynamics provide the bottom-up drive that selects which stored pattern is relevant. This makes the model formally comparable to transformer-style classifiers while remaining grounded in cortical and hippocampal anatomy.

The closest prior integration work is DIME/EBPM [4], which uses a controller that *switches* between an engram module and a PC module. SEPCN differs in being a single architecture: PC and engram are not separate modules with a router; the engram is the top of the PC hierarchy, and the PC dynamics are what allocate it.

## 2. Architecture

### 2.1 Cell populations and layered structure

SEPCN has four functional layers, each defined by a population of rate-based units with a corresponding population of error units. The model is rate-based for clarity; a spiking extension is straightforward and noted in §10.

| Layer | Functional role | Sparsity | Biological analogue |
|---|---|---|---|
| L0 (input) | Pixel / feature values | Dense | Sensory thalamus / V1 L4 |
| L1 (feature) | Local feature extraction | ~30–50% active | V1 L2/3 + L5/6 (cortical microcircuit) |
| L2 (object) | Distributed object representation | ~10–20% active | Inferotemporal cortex (IT) |
| L3 (engram) | Sparse categorical read-out | ~2–5% active | Dentate gyrus / CA3 category engram cells |

Each layer `ℓ` has two subpopulations: a *value* population `z^ℓ` that holds the current best estimate of the layer's activity, and an *error* population `ε^ℓ` that holds the local prediction error `ε^ℓ = z^ℓ − f(W^{ℓ+1} z^{ℓ+1})` against the top-down prediction from the layer above. This is the standard PC parameterisation of Whittington and Bogacz [2,5], extended by the addition of an engram layer (L3) on top.

The L3 engram population is *sparse by construction*. It contains `N_E` excitatory units, of which only `k = 0.02·N_E` to `0.05·N_E` are active for any given input. This matches the empirically observed sparsity of dentate gyrus granule cells (2–5% activation per experience) [6,7] and the mossy-fibre detonator principle [8]. The sparsity is enforced by a population of PV-positive interneurons that compute a soft k-WTA over the engram units: only the `k` units with the highest input drive escape lateral inhibition and emit activity. Sparser code is also the natural inductive bias for a categorical top layer: with `k/N ≈ 0.03`, the expected overlap between codes for two unrelated inputs is `k²/N ≈ 0.001`—orders of magnitude lower than for dense codes, and the empirical reason DG pattern separation works so well.

### 2.2 Connectivity and information flow

Three connection families carry information, all local:

- **Top-down generative weights `W^{ℓ+1→ℓ}`**: from value population `z^{ℓ+1}` to error population `ε^ℓ`. These are the "predictor" synapses; in the standard PC reading they compute the top-down prediction of the layer below.
- **Bottom-up error weights `W^{ℓ→ℓ+1}`**: from error population `ε^ℓ` to value population `z^{ℓ+1}`. These carry the residual upward, and the activity update that drives the next layer toward agreement with what the lower layer actually said.
- **Lateral engram-recurrent weights `W^{en→en}` (L3 only)**: from each engram unit to every other engram unit in the same cluster. These implement the auto-associative completion that the hippocampal CA3 recurrent collaterals are known to perform [9,10]. Together with the k-WTA, they give the engram layer a small-world attractor structure that retrieves the full engram pattern from a partial cue.

There is no weight-transport symmetry between top-down and bottom-up weights: `W^{ℓ+1→ℓ}` and `W^{ℓ→ℓ+1}` are learned independently. This removes the single most-cited biological implausibility of backprop [11].

## 3. Dynamics

### 3.1 Free energy and activity update

Inference in SEPCN minimises a layer-local variational free energy. Let the full state be `z = (z^0, z^1, z^2, z^3)` and the input be clamped at `z^0 = x`. The free energy is

```
F(z; x) = Σ_{ℓ=1..3} ½ ‖z^ℓ − f(W^{ℓ+1} z^{ℓ+1})‖²_Σℓ + R(z^3)
```

where the first sum is the standard PC sum of squared local prediction errors (precision-weighted), and `R(z^3)` is a sparsity regulariser on the engram layer that implements the k-WTA penalty. Following Whittington and Bogacz [2], the activity update for layer `ℓ` is the gradient flow on `F` with respect to `z^ℓ`:

```
τ · ż^ℓ = −∂F/∂z^ℓ = ε^ℓ − f'(z^ℓ) · Σ^{ℓ−1} + W^{ℓ+1⊤} ε^{ℓ+1}
```

That is, each layer's activity is updated by a *local* combination of its own prediction error and the gradient of its top-down prediction (when there is a layer above) and the gradient passed up from the layer below (when there is a layer below). The dynamics are local: each unit only needs information accessible at its own synapses. This is the form Whittington and Bogacz showed, under γ = 0.5 and small error, to be equivalent to backpropagation [2,5]; the SEPCN innovation is not in this part of the dynamics but in what sits on top of them.

### 3.2 Engram-layer sparsity via k-WTA

At the engram layer, the sparsity penalty is implemented biologically by PV-positive interneurons that pool engram-unit activity and deliver divisive inhibition. In rate form:

```
z^3_i = σ(β · (I_i − α · Σ_{j≠i} z^3_j) − γ_en · (Σ_j z^3_j − k)_+)
```

where `I_i` is the bottom-up drive to engram unit `i`, `σ` is a soft-threshold, the `α·Σ z^3_j` term is the lateral-inhibition component, and the last term penalises any population activity above `k`. The result is approximate k-WTA: the `k` units with the largest `I_i` fire; the rest are silenced. The k-WTA is not a separate algorithmic stage—it is a *local* circuit implemented by interneurons that respect Dale's law.

This sparsity has a precise computational consequence: the bottom-up drive to the engram layer is converted, by the k-WTA, into a *categorical* representation. The set of engram units that fire is determined by the input; the magnitude of firing within that set is approximately constant. This is the network's classification hypothesis at any given inference step.

### 3.3 CREB-like excitability allocation

The key biological piece is engram allocation. Yiu et al. [12] showed that neurons with relatively higher intrinsic excitability at the time of learning are preferentially recruited into a fear-memory engram; Han et al. [13] showed that CREB overexpression raises the chance of allocation roughly four-fold. SEPCN implements this with a local *excitability variable* `θ_i` for each engram unit, updated by

```
τ_θ · dθ_i/dt = (z^3_i − z^3_baseline) − λ_θ · (θ_i − θ_baseline)
```

i.e., each time a unit fires above baseline during inference, its excitability is boosted; the boost decays back to baseline on a slow timescale (hours, in biology). When a new input drives the engram layer, the units with the highest `θ_i + I_i` win the k-WTA. Once a unit has won repeatedly, its `θ_i` is persistently high, and the same unit tends to win again. This is the recruitment rule: the unit that fires most reliably for a given input becomes the engram cell for that input's category.

Yiu et al. [12] further showed that direct artificial excitability elevation (via CREB overexpression, DREADDs, or K⁺-channel knockdown) biases allocation. The SEPCN rule is consistent with this: any process that elevates `θ_i` for a unit makes that unit more likely to be recruited. Conversely, depressing `θ_i` (e.g., by activating Kir2.1 channels) excludes a unit from the engram. The model predicts a continuous rather than binary allocation probability, scaled by `θ_i`—a quantitative prediction that can be tested against the Yiu data.

## 4. Learning Rules

### 4.1 Fast weight update (predictive-coding equivalence)

After the activity dynamics settle (typically T = 10–20 iterations, with `τ_γ` the time-constant ratio from Whittington and Bogacz [2,5]), the weights are updated by a local Hebbian rule of the form

```
ΔW^{ℓ+1→ℓ} ∝ ε^ℓ · f(z^{ℓ+1})  (top-down)
ΔW^{ℓ→ℓ+1} ∝ ε^ℓ · f(z^ℓ)      (bottom-up, when applicable)
```

These are *local* plasticity rules: each synapse only needs the pre- and post-synaptic activity that are already present at that synapse. The two rules are not symmetric in general; the model is not subject to the weight-transport problem. The update, when `γ = 0.5`, recovers the backpropagation weight update under small-error conditions [2,5]; the spiking extension recovers it under a slightly relaxed condition [14].

Crucially, the top-down weight from the engram layer (L3) to the object layer (L2) is a *pattern-completion* synapse: it stores the feature-pattern associated with each engram cluster. The bottom-up weight from the object error to the engram activity is a *cueing* synapse: it computes, for each engram cluster, how well the current object-layer state matches that engram's stored feature. Together with the L3 lateral weights, this is mathematically the same arrangement as a Modern Hopfield network with stored patterns `X` (the engram feature weights) and query `z^2` (the object-layer activity) [3].

### 4.2 Inhibitory plasticity and selectivity

Tomé et al. [15] showed that engrams in dentate gyrus are *dynamic*—only 10–40% of training-activated cells are reactivated at remote recall—and that CCK-positive interneurons mediate an inhibitory-plasticity rule that sculpts engram selectivity over hours. SEPCN includes a slow inhibitory-plasticity rule on the engram-layer interneurons, distinct from the fast excitatory rule on the principal cells:

```
ΔW^{inh}_{i→j} ∝ z^3_i · (z^3_j − p_j^{target}) · slow_time_constant
```

where `p_j^{target}` is the desired post-learning firing rate of engram unit `j` for its preferred input (close to 1; close to 0 for non-preferred). This rule tightens the selectivity of each engram cluster over the consolidation period: engram units that fire for off-target inputs get more inhibition; engram units that fire for their preferred input get less. The result is a more selective, sharper engram after consolidation than immediately after encoding—matching the experimental finding that memory specificity emerges over ~12 hours [15].

The PV-positive interneurons implementing the k-WTA are distinct from the CCK-positive interneurons implementing selectivity; this matches the dual-interneuron architecture in DG [15,16].

### 4.3 Slow off-line consolidation (replay)

During an "off-line" phase (modelled as quiescent periods in the animal; in vitro, a sleep-like state), the system replays stored engram patterns. Specifically, the engram layer stochastically activates a previously stored engram cluster, and the resulting top-down drive is used as a target for slow plasticity in the feature and object layers:

```
ΔW^{ℓ+1→ℓ}_{slow} ∝ ε^ℓ · f(z^{ℓ+1}_replay)  with learning rate η_slow << η_fast
```

This is the SEPCN analogue of sharp-wave-ripple replay [17,18]: engram patterns are reactivated and the slower feature/object weights are adjusted toward them, distributing the engram's information into a more generalisable cortical-style representation. Girardeau et al. [17] and Ego-Stengel and Wilson [18] showed that disrupting SWRs impairs memory consolidation; the SEPCN prediction is that blocking the slow plasticity rule (or the replay mechanism) leads to exactly this impairment—engram cells persist, but the feature layer never learns to generalise from them, so familiar inputs fail to reactivate the correct engram under noise.

The two-timescale structure (fast engram allocation, slow feature generalisation) is the implementation of Complementary Learning Systems [19] inside one architecture, not two stacked modules.

## 5. Classification Pathway

A new input `x` is classified by the following procedure:

1. Clamp `z^0 = x`. Initialise `z^1, z^2, z^3` to their prior values (or zero).
2. Run activity dynamics for T iterations. The engram layer's k-WTA settles to a sparse pattern of `k` active units.
3. Cluster the active engram units (by lateral weights): the densest cluster is the predicted class.
4. If no cluster is dense enough above a confidence threshold, the input is "novel"; the system allocates a new engram cluster for it.

The classification read-out is a Modern Hopfield update `z^3 ← X · softmax(β Xᵀ z^2)` followed by k-WTA, embedded inside a PC inference loop. The PC dynamics provide the bottom-up drive that selects which stored pattern is relevant; the engram layer's lateral weights and k-WTA enforce the categorical read-out. Inference typically converges in 10–20 iterations; this is a small constant overhead compared to a single feedforward pass in a standard neural network classifier.

Training proceeds in mini-batches: present `(x, y)`, clamp `z^3` to the engram cluster of class `y` (or let the k-WTA select it from input plus label drive), run inference to settle `z^1, z^2, z^3`, then apply the fast weight update. After each batch, run a short off-line phase that replays a random sample of stored engrams into the slow weights.

## 6. Biological Mapping

| SEPCN component | Biological substrate | Supporting evidence |
|---|---|---|
| Input layer L0 | Sensory thalamus, retinal / LGN input | Standard |
| Feature layer L1 (values + errors) | Cortical microcircuit: L2/3 errors, L5/6 predictions | [20] |
| Object layer L2 | Inferotemporal / perirhinal cortex | [21] |
| Engram layer L3 (sparse, k-WTA) | Dentate gyrus granule cells (sparse) + CA3 auto-associative completion | [8,9,10] |
| k-WTA via PV interneurons | Dentate PV+ basket cells | [16] |
| Slow inhibitory plasticity | DG CCK+ interneurons | [15] |
| Excitability allocation `θ_i` | CREB-dependent intrinsic excitability | [12,13] |
| Replay → slow plasticity | Sharp-wave-ripple replay during quiet wakefulness / NREM | [17,18] |
| Comparator-like error computation | CA1: SC (Schaffer, prediction from CA3) on proximal dendrites + temporoammonic (sensory) on distal dendrites | [22,23] |
| ACh modulation of allocation | High ACh suppresses CA3 input → encoding mode; low ACh → retrieval mode | [24] |

A subtlety: the four-layer abstraction collapses a real brain-wide engram complex into a single cortical layer. A 2022 whole-brain imaging study found that a single contextual fear memory recruits engram cells in 117 brain regions [25]. SEPCN's "engram layer" should be read as a computational abstraction of this distributed complex, not as a single anatomical layer. The architecture can in principle be tiled: replace the single L3 engram layer with a hierarchy of engram layers coupled by the same PC dynamics, mirroring the thalamo-cortical dialogue that systems-consolidation models rely on [26].

## 7. Evaluation Scenarios

The model is designed to be evaluated on three classification tasks that exercise its integration of engrams and PC:

**MNIST baseline.** Architecture: 784 (input) → 500 (L1) → 500 (L2) → 2000 (L3) with k = 60 (3% sparsity). Expected test accuracy: 97–98%, comparable to the original PCN [2,5,27]. The accuracy number is not the main point; the point is that the engram layer does not hurt the PCN baseline.

**Split-MNIST continual learning.** Train on digits 0–4, then 5–9, sequentially. The CLS-style two-timescale structure (fast engram allocation, slow feature generalisation via replay) predicts low catastrophic forgetting—engram cells for 0–4 persist even as 5–9 engrams are allocated, because the fast weights for the engram layer do not overlap with the slow feature-layer weights that interfere. Expected: ≤ 5% forgetting of the first task, comparable to EWC [28] and replay-buffer approaches but without an explicit replay buffer—the replay is in the SWR-style off-line phase.

**Few-shot MNIST (1–5 shots per class).** Because each new class can be allocated as an engram cluster after a single exposure, the model should reach 80%+ accuracy on 5-shot MNIST, comparable to prototypical networks and Modern Hopfield classifiers [3,29]. This is the clearest test of the CREB-like allocation rule: a single exposure should suffice to recruit a new engram cluster, which is the model's prediction and Han et al.'s [13] experimental observation.

**Noise robustness / pattern completion.** Present a corrupted or partial input; measure whether the correct engram cluster reactivates. SEPCN predicts robust pattern completion because the engram layer's lateral auto-associative weights + k-WTA can retrieve the full engram from a partial bottom-up drive.

## 8. Testable Predictions

The model's design yields several predictions that distinguish it from either pure PC or pure Hopfield, and that can be tested in biological experiments or in the simulation:

1. **Engram turnover predicts selectivity.** In the simulation, the engram cells that persist for > 24 hours are a subset (the 10–40% that the model predicts and Tomé et al. [15] observed) of those active at encoding. The persisting cells are those that *also* received the slow inhibitory sculpting. The prediction: optogenetic silencing of the persisting subset should abolish remote-memory retrieval, while silencing only the original encoding subset should leave remote retrieval intact.

2. **CCK+ interneuron silencing reduces classification selectivity without affecting the engram population size.** The slow inhibitory-plasticity rule on CCK+ cells tightens the off-target suppression around each engram cluster. Silencing CCK+ cells in the model (matching Tomé et al.'s [15] experiment) should leave the engram ensemble intact but degrade the discrimination index. This prediction is testable in mice: chemogenetic silencing of DG CCK+ interneurons should reduce freezing in a similar-but-not-identical context without abolishing freezing in the training context itself.

3. **ACh modulates the inference time of classification.** High ACh suppresses the CA3-style lateral drive in the engram layer and emphasises bottom-up drive; this is encoding mode. Low ACh emphasises lateral drive; this is retrieval mode [24]. The model's prediction: in a familiar stimulus, lowering ACh (e.g., with scopolamine) should speed up classification inference but hurt the discrimination between similar inputs; raising ACh should slow inference but improve discrimination. This is a novel, falsifiable prediction of the model that can be tested in behaving animals.

4. **The sparsity–accuracy trade-off is not monotonic.** Increasing engram-layer sparsity improves pattern separation and reduces interference but raises the number of inference iterations needed to find the correct k-WTA winner. The model predicts a U-shaped accuracy-vs-sparsity curve with an optimum near 2–5%, matching the biological range [6,7].

5. **Disrupting replay during a "sleep" phase should impair the slow-time-scale feature-layer learning, leaving fast engram allocation intact.** This is the SWR-disruption result of Girardeau et al. [17] and Ego-Stengel and Wilson [18]; SEPCN predicts that the *fast* engram layer can still allocate new engrams during encoding, but the slow feature-layer generalisation never happens, so familiar inputs are correctly classified only when the input is close to an exact engram cue, not when it is a novel-but-similar input.

SEPCN is the only model in the table in which the engram and the PC are not separate modules but the same computation seen at two timescales. This is the integration that the question asks for: the engram is not a memory store that PC reads; it is a *generative prior* whose cells are recruited by the PC dynamics themselves.

## 10. Limitations and Open Questions

The model is honest about its uncertainties.

**Spiking extension.** The rate-based form above is for clarity. A spiking version with conductance-based synapses, triplet STDP, and adaptive thresholds is feasible (cf. Diehl & Cook's 95% MNIST spiking network [32]) and would strengthen the biological case. The k-WTA can be implemented with inhibitory interneurons; the excitability rule can be implemented with a slow CREB-like gain variable.

**Allocation rule shape.** The exact equation for `θ_i` update is a model design choice. The data constrain the *principle* (excitability biases allocation; ~4x magnitude [13]) but not the precise form. The model's quantitative predictions (sparsity–accuracy trade-off, ACh effect on inference time) are robust to small variations in the rule.

**Replay mechanism.** The off-line replay phase is implemented as a simple loop. The biological mechanism involves thalamo-cortical SWR-ripple coupling [17,18], coordinated by the thalamus, and the fact that 117 brain regions participate in a single engram [25] suggests that real replay is more structured than a uniform random draw. The model can in principle be extended to a coupled thalamic replay driver, but this is beyond the current scope.

**Scaling.** The model's MNIST and continual-learning scenarios are tractable; CIFAR-10 with a convolutional variant and ImageNet are open questions. The bottleneck is not the algorithm but the absence of a published large-scale biologically plausible classifier with engram-style top layers; the model is a foundation for such a scaling study, not a finished one.

**Engram abstraction.** The single engram layer is a computational abstraction of a brain-wide engram complex [25]. The architecture can be extended by tiling engram layers across cortical regions with the same PC dynamics, but this extension has not been worked out.

**Two-timescale coupling.** The slow feature-layer learning is initialised by the fast engram allocation, but the reverse coupling (slow learning updating the engram-layer priors) is not modelled. A full CLS-style model would add this; it is a natural next step.

Despite these caveats, SEPCN delivers the integration the question asks for: a single network in which the engram is the top of a PC hierarchy, PC error signals recruit engram cells via a CREB-like excitability rule, slow replay-based consolidation generalises engrams into a feature-layer representation, and classification emerges as a Modern-Hopfield-style read-out of the winning engram cluster.
