# 1. 技术方法概述

> **合规说明**：本报告仅依据题目所给资料及其列出的来源进行综合整理；未使用、未引用用户明确禁止的文章及其相关 URL。报告假定当前日期为 **2026 年 10 月 10 日**。

## 1.1 发酵前策略：在糖转化为乙醇之前降低“潜在酒精度”

发酵前策略的共同逻辑是：**减少葡萄或葡萄汁中可发酵糖的积累或有效含量**，使酵母在后续酒精发酵中可转化为乙醇的底物减少。相较于发酵后脱醇，这类方法通常更能保留“葡萄酒原生结构”，但对成熟度、酸度、香气前体和酚类成熟的影响更复杂，尤其受品种、气候和采收目标制约。已有综述将发酵前降醇路径概括为早采/调配、汁液稀释、膜法除糖、葡萄糖氧化酶处理，以及通过降低光合能力、减少叶面积、调节灌溉等栽培措施降低糖积累（[IntechOpen, 2022](https://www.intechopen.com/chapters/82466)）。

### 1.1.1 叶面积减少法 / 果穗区摘叶

**核心原理**：通过减少叶面积、改变果穗区光照和温度条件，间接影响浆果糖积累、酸降解和二级代谢物合成。传统果穗区摘叶通常移除果穗附近约 **40%–100%** 的叶片，相当于约 **2–5 片叶**；在强光或高暴露环境中，单侧、尤其较凉一侧摘叶可降低日灼风险（[Penn State Extension, 2015](https://psuwineandgrapes.wordpress.com/2015/09/11/an-overview-of-cluster-zone-leaf-removal-strategies-for-cool-climate-vineyards/)）。

从降醇角度看，叶面积减少法不是“直接除糖”技术，而是通过降低光合碳供应、调节成熟速度或降低产量来影响最终潜在酒精度。其品质影响具有明显的气候依赖性。在冷凉产区，增加果穗日照可促进花色苷合成、单萜形成、甲氧基吡嗪降解，并常因苹果酸降低而使滴定酸下降；这对酸度偏高、青味偏重的果实可能有利（[Penn State Extension, 2015](https://psuwineandgrapes.wordpress.com/2015/09/11/an-overview-of-cluster-zone-leaf-removal-strategies-for-cool-climate-vineyards/)）。但在半干旱或温暖产区，过度或过早摘叶可能带来产量惩罚、苹果酸过度下降、果实暴晒和香气失衡等风险；早期摘叶研究也提示，果实日照增加通常提高可溶性固形物、花色苷和酚类，同时降低滴定酸、苹果酸、pH 和果粒重，但需谨慎权衡产量损失（[Risco et al., 2010](https://ives-openscience.eu/wp-content/uploads/2023/03/Can_Early_Defoliation_Risco.pdf)）。

**研究判断**：叶面积减少法更适合作为“风味成熟度和酸度管理工具”，而非单独的降醇工具。若目标是稳定降低 1%–3% v/v 酒精度，仅靠摘叶并不可靠；但它可与早采、调配或低强度后脱醇组合使用。

### 1.1.2 提早采收与调配

**核心原理**：在葡萄糖度尚未达到传统成熟高点时采收，获得较低可发酵糖的基酒，再与较成熟批次调配，以降低最终酒精度并保留部分成熟风味。文献中提早采收结合调配可实现约 **3.0%–3.2% v/v** 的酒精度降低，但早采果可能带来较高酸感、草本或“生青”香气，需要通过调配平衡（[IntechOpen, 2022](https://www.intechopen.com/chapters/82466)）。

该策略的优点是技术门槛低、无需昂贵设备，并且避免后期强制脱醇导致的大量挥发香气损失。但其关键风险在于“糖成熟”和“酚类/香气成熟”不同步：糖度低并不等于风味成熟。红葡萄酒尤其可能出现单宁粗糙、颜色不足或果香不完整；白葡萄酒则可能酸度突出、口感尖锐。

**研究判断**：对于原料糖度过高但风味成熟较早的产区，提早采收是性价比较高的策略；但在冷凉年份或晚熟品种上，早采带来的风味不成熟可能比酒精度偏高更损害品质。

### 1.1.3 葡萄汁稀释 / 加水调糖

**核心原理**：在发酵前向高糖葡萄汁或醪中加入水，降低单位体积糖浓度，从而降低理论乙醇产量。澳大利亚葡萄酒研究所指出，加水可用于降低高糖汁液的糖度，并减少滞缓或停滞发酵风险；实践上需重新测定 Brix/Bé、pH 和滴定酸，并注意水质、氯/氯胺去除及法规限制（[AWRI, 2020](https://www.awri.com.au/industry_support/winemaking_resources/winemaking-practices/winemaking-treatment-water-addition/)）。

稀释法的优点是简单、成本低、降醇效果可计算；缺点是可能同步稀释酸、矿物质、酚类、香气前体和非挥发基质，造成酒体变薄、风味稀释。若用于红葡萄酒，尤其需关注颜色、单宁和中后段口感被削弱的问题。

**研究判断**：葡萄汁稀释适合作为“纠正极端高糖原料”的工具，而不宜作为追求高品质低醇酒的主要技术。其品质风险不是单纯来自加水本身，而是来自非挥发结构物质被整体稀释。

### 1.1.4 葡萄糖氧化酶添加法（GOX）

**核心原理**：在发酵前利用葡萄糖氧化酶将葡萄糖氧化为葡萄糖酸，减少可被酵母转化为乙醇的葡萄糖。Pickering 等的研究显示，Müller-Thurgau 和 Riesling 葡萄汁经 GOX 处理后葡萄糖转化效率分别达到 **87%** 和 **74%**，所得酒精度约 **6.3%–6.5% v/v**，较对照降低 **36%–40%**（[Pickering et al., 1999](https://hero.epa.gov/reference/4941335/)）。

GOX 的主要副作用是酸结构显著改变：大量葡萄糖酸生成并保留在成酒中，pH 与对照相近，但滴定酸显著升高（[Pickering et al., 1999](https://hero.epa.gov/reference/4941335/)）。后续研究摘要还指出，GOX 酒中酯类和脂肪酸浓度可能更高，可能与汁液氨基酸组成变化有关；同时 GOX 酒颜色更金黄、SO₂ 结合能力增加，果香强度和风味长度可能因处理过程所需通气而下降（[Pickering, 1997](https://agris.fao.org/search/en/providers/125257/records/6765998d6784547a43e37328)）。

**研究判断**：GOX 是降醇幅度最大的发酵前技术之一，但更适合白葡萄酒、低醇酒或特定风格开发。其主要技术瓶颈不是“能否降醇”，而是葡萄糖酸、酸感、氧化色泽和果香损失是否能被风格接受。

### 1.1.5 发酵前膜法除糖：纳滤、反渗透及组合膜系统

**核心原理**：在发酵前对葡萄汁进行膜分离，选择性去除部分糖或获得低糖馏分，再回配进入原汁。纳滤（NF）和反渗透（RO）可通过压力驱动膜分离降低可发酵糖，属于预发酵降低潜在酒精度的路径之一（[IntechOpen, 2022](https://www.intechopen.com/chapters/82466)）。

与加水相比，膜法除糖理论上可减少对整体基质的稀释，但设备成本、膜污染、处理速度和香气/营养物质损失是实际限制。若去除的是葡萄汁中的糖，还需关注氮源、矿物质和香气前体是否随透过液损失，从而影响后续发酵动力学和香气生成。

## 1.2 发酵中策略：改变糖向乙醇的代谢去向

发酵中策略并不一定减少初始糖含量，而是试图使部分碳流不进入乙醇，而转向甘油、有机酸、生物量、挥发性副产物，甚至被部分微生物直接消耗。该路径的核心优势是可与常规酿造兼容，设备要求低；核心风险是发酵可控性、残糖、挥发酸和香气重现性。

### 1.2.1 非酿酒酵母与混合发酵

**核心原理**：利用部分非酿酒酵母（non-*Saccharomyces*）将糖转化为乙醇以外的代谢物，如甘油、有机酸、生物量或其他挥发性化合物，再由 *Saccharomyces cerevisiae* 完成发酵。历史上非酿酒酵母因可产生乙酸、乙酸乙酯、乙醛和异味而被视为污染风险，但现在许多种被重新评价为提升香气复杂度和降低酒精度的工具（[Carbon, 2023](https://rex.libraries.wsu.edu/view/pdfCoverPage?instCode=01ALLIANCE_WSU&filePid=13397236320001842&download=true)）。

常见应用方式包括**共接种**和**顺序接种**。共接种是非酿酒酵母与 *S. cerevisiae* 同时以较高细胞浓度加入；顺序接种则让非酿酒酵母先发酵一段时间，再加入 *S. cerevisiae* 完成发酵（[Penn State Extension, 2019](https://psuwineandgrapes.wordpress.com/2019/09/26/non-saccharomyces-yeast-in-winemaking/)）。由于许多非酿酒酵母发酵能力弱、耐酒精性低，通常仍需 *S. cerevisiae* 收尾，以降低残糖和停滞发酵风险（[Penn State Extension, 2019](https://psuwineandgrapes.wordpress.com/2019/09/26/non-saccharomyces-yeast-in-winemaking/)）。

研究显示，非酿酒酵母可通过多条碳流机制降低乙醇，包括较高甘油产量、有机酸生成、生物量积累，以及某些菌株直接消耗乙醇（[Carbon, 2023](https://rex.libraries.wsu.edu/view/pdfCoverPage?instCode=01ALLIANCE_WSU&filePid=13397236320001842&download=true)）。例如在 Chambourcin 微发酵研究中，*Hanseniaspora uvarum* 与 EC1118 混合发酵的乙醇水平低于 EC1118 单独发酵，并表现出较低乙醇得率，提示碳流转向其他副产物（[Tin, 2023](https://etda.libraries.psu.edu/catalog/25006lkt5295)）。但 2024 年 Sauvignon blanc 研究也显示，*Torulaspora delbrueckii* 与 *H. uvarum* 混合发酵虽观察到较低乙醇趋势，但乙醇差异未必显著；其更稳定的价值可能体现在提高酯类、乙酸酯和香气复杂度（[Wang et al., 2024](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2024.1413650/full)）。

非酿酒酵母的另一个关键点是氮源竞争。葡萄汁中酵母可同化氮（YAN）主要由铵态氮和氨基酸构成，是酵母生长、发酵动力学和挥发性香气形成的控制点；*S. cerevisiae* 通常需要约 **120–140 mg N/L** YAN 才能获得满意发酵动力学和成酒质量（[Gobert et al., 2017](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2017.02175/full)）。不同非酿酒酵母具有明显氮源偏好：*Starmerella bacillaris* 不消耗组氨酸、蛋氨酸、苏氨酸和酪氨酸；*Metschnikowia pulcherrima* 同化天冬氨酸很慢；*Pichia membranifaciens* 不同化谷氨酰胺；半胱氨酸则是三者偏好的氮源（[Gobert et al., 2017](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2017.02175/full)）。因此顺序接种中若前期非酿酒酵母消耗 YAN，后续 *S. cerevisiae* 可能出现发酵性能下降和香气谱改变（[Gobert et al., 2017](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2017.02175/full)）。

**研究判断**：非酿酒酵母是当前最有潜力的“低成本、风味正向”降醇路径，但不应被视为稳定大幅降醇工具。其合理定位是降低约小幅至中等酒精度，同时重塑香气；菌株筛选、YAN 管理、SO₂、温度和接种时序是成败关键。

### 1.2.2 营养限制与温度控制

**核心原理**：通过控制 YAN、氧、脂类、温度等发酵条件，改变酵母生长、糖消耗速率、挥发性代谢物和副产物生成。发酵条件会影响 *S. cerevisiae* 的高级醇和酯形成；半好氧条件下乙醇、异戊醇、异丁醇、苯乙醇及多种乙酸酯产量更高，而厌氧条件下细胞生长较低，部分醇类产量上升（[Mauricio et al., 1997](https://hero.epa.gov/reference/2113450/)）。

需要强调的是，**营养限制并不是可靠的主要降醇技术**。YAN 缺乏是停滞或滞缓发酵的重要原因，可能导致残糖升高、挥发酸上升和微生物稳定性下降（[Gobert et al., 2017](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2017.02175/full)）。温度降低可改变氮同化和膜转运，但也可能延长发酵周期、改变酯类形成，并增加发酵管理难度。

**研究判断**：营养和温度控制应作为非酿酒酵母、低糖原料或膜处理汁液的“风险管理工具”，而非单独追求降醇的手段。刻意压低 YAN 来降醇属于高风险做法，不适合商业化稳定生产。

## 1.3 发酵后策略：从成酒中选择性移除乙醇

发酵后策略是在酒精发酵完成后去除乙醇，技术上可控性强，适合既有成酒的酒精度调整和无醇/低醇产品开发。其共同挑战是：乙醇不仅贡献酒精含量，还影响香气挥发、口感体积、甜感、热感、结构和微生物稳定性；过度脱醇往往导致香气、口感和消费者接受度下降（[Longo et al., 2024](https://link.springer.com/article/10.1007/s11947-024-03336-w)）。

2024 年综述指出，去除 **1%–4% v/v** 乙醇的部分脱醇通常可保留相当多的酚类、挥发物和感官属性；但当成酒酒精度低于约 **3% v/v** 时，挥发性化合物损失可能超过 **90%**，感官质量明显下降（[Longo et al., 2024](https://link.springer.com/article/10.1007/s11947-024-03336-w)）。这一点是选择技术路线时最重要的边界条件。

### 1.3.1 膜分离技术：NF、RO、OD、渗透汽化与多级膜系统

商业相关的物理脱醇方法可分为两大类：膜分离和热蒸馏。膜分离包括纳滤、反渗透、蒸发渗透/渗透蒸馏、渗透汽化和透析等；热法包括真空蒸馏和旋转锥柱（[Sam et al., 2021](https://agris.fao.org/search/en/providers/122535/records/65dff6c2b766d82b180398d9)）。

**纳滤（NF）** 以压力驱动膜分离为基础，孔径和截留特性介于超滤与反渗透之间，可用于部分酒精或糖分调整。其优点是低温操作、对热敏香气较温和；缺点是小分子香气和乙醇选择性难以完全分离，膜污染和处理成本需考虑。

**反渗透（RO）** 是应用较广的技术，可在低温下逐步降低酒精度。RO 通过半透膜将酒分为含水和乙醇的透过液，以及保留较多非挥发组分的浓缩酒体；再处理透过液去除乙醇后回配水分。其优点是低温、可渐进式调整、避免高热损伤；缺点是需多次循环、速度较慢，且挥发性香气可随膜透过而损失（[Winesecrets, 2024](https://winesecrets.com/the-art-and-science-of-dealcoholizing/)）。

**渗透蒸馏（OD）** 和 **渗透汽化（Pervaporation）** 属膜接触/膜传质技术，利用膜两侧乙醇活度、蒸气压或浓度差，将乙醇从酒中转移到汽相或萃取相。相较直接热蒸馏，它们温度较低，但仍可能损失乙酯、萜烯等小分子高挥发香气。2024 年综述指出，不同脱醇技术的挥发物损失与过程蒸气压、温度、膜性质和香气化合物理化性质相关，且所有技术在大幅去除乙醇时都难以避免显著香气损失（[Longo et al., 2024](https://link.springer.com/article/10.1007/s11947-024-03336-w)）。

**多级膜系统** 通常将 RO 与 OD、透析或其他膜过程组合，以先浓缩或分离乙醇/水馏分，再进行二级去醇或回配。近期比较研究显示，膜法尤其是 RO 结合 OD 的系统，在关键化合物保留和颜色稳定性方面可能优于部分热法；而真空蒸馏和传统蒸馏更容易造成颜色降解（[IVES, 2025](https://ives-openscience.eu/52857/)）。

### 1.3.2 热法：真空蒸馏与旋转锥柱

**真空蒸馏（VD）** 的核心原理是通过降低压力降低乙醇沸点，使乙醇在较低温度下蒸发，以减少热损伤。资料显示，真空条件下乙醇沸点可降至约 **40°C**（[Infowine, 2024a](https://www.infowine.com/en/wine-dealcoholization-techniques-effects-and-current-challenges/)）。VD 适合快速、较大规模去除乙醇，但热敏香气、颜色和部分挥发物仍可能受损；较高温度和较强脱醇幅度会加剧挥发物损失（[Longo et al., 2024](https://link.springer.com/article/10.1007/s11947-024-03336-w)）。

**旋转锥柱（SCC）** 是目前酿酒中应用最广的脱醇技术之一。其设备内部由固定锥和旋转锥组成，酒液形成薄膜，在真空和低温下快速高效移除乙醇（[Infowine, 2024a](https://www.infowine.com/en/wine-dealcoholization-techniques-effects-and-current-challenges/)）。SCC 的关键优势是香气回收：可先在约 **28–30°C** 蒸馏出含乙醇和多种挥发物的香气馏分并保留，再在约 **38°C** 去除乙醇，最后将香气馏分回配，以降低香气损失（[Infowine, 2024b](https://www.infowine.com/en/wine-dealcoholization-most-used-techniques/)）。

不过，SCC 也不能完全避免品质变化。消费者拒绝阈值研究显示，Chardonnay 经 SCC 脱醇至约 **2.8% v/v** 时可能变得不可接受，而 Syrah 的阈值约 **7.0% v/v**；另有研究观察到 Chardonnay 从 14.9% 降至 12.9% v/v 后，整体香气强度和热感下降（[Longo et al., 2024](https://link.springer.com/article/10.1007/s11947-024-03336-w)）。

**综合研究判断**：若目标是商业上稳定降低 **1%–4% v/v** 酒精度，优先考虑“适度后脱醇 + 香气回收/回配”的路线；若目标是低于 0.5% v/v 的无醇酒，仅依靠后脱醇很难保持传统葡萄酒感官完整性，必须通过基酒设计、香气回配、酸甜平衡和口感重建共同完成。

# 2. 技术影响对比表

| 技术名称 | 对葡萄酒成分的主要改变 | 对感官属性的影响 |
|---|---|---|
| 叶面积减少法 / 果穗区摘叶 | 改变果穗区光照和温度；冷凉区可促进花色苷、单萜形成，促进甲氧基吡嗪降解，并常因苹果酸降低而降低滴定酸；过度或过早处理可能造成产量下降和酸结构变化（[Penn State Extension, 2015](https://psuwineandgrapes.wordpress.com/2015/09/11/an-overview-of-cluster-zone-leaf-removal-strategies-for-cool-climate-vineyards/)）。 | 可减少青味、提升颜色和成熟香气；强光区可能出现日灼、果香损失、酸度不足或成熟不均。作为降醇技术稳定性有限，更适合调控成熟和风味。 |
| 提早采收 | 降低初始糖度，从源头降低潜在乙醇；可能伴随较高苹果酸和滴定酸、较低 pH、较低酚类成熟度；与成熟批次调配可实现约 3.0%–3.2% v/v 降醇（[IntechOpen, 2022](https://www.intechopen.com/chapters/82466)）。 | 酸感增强，酒体较轻；若采收过早，可能出现生青、草本、单宁粗糙或香气不完整。调配可缓和缺陷。 |
| 葡萄汁稀释 | 降低糖浓度和潜在乙醇；同时可能稀释酸、矿物质、酚类、香气前体和非挥发基质；需重新测定 Brix、pH 和 TA（[AWRI, 2020](https://www.awri.com.au/industry_support/winemaking_resources/winemaking-practices/winemaking-treatment-water-addition/)）。 | 降醇直接且可预测，但可能造成酒体变薄、风味稀释、结构松散。适合极端高糖原料纠偏，不宜过量使用。 |
| 葡萄糖氧化酶添加法（GOX） | 将葡萄糖转化为葡萄糖酸；Müller-Thurgau 和 Riesling 中葡萄糖转化率可达 87% 和 74%，成酒约 6.3%–6.5% v/v，降醇 36%–40%；pH 接近对照但 TA 显著升高（[Pickering et al., 1999](https://hero.epa.gov/reference/4941335/)）。 | 酸感增强，可能出现更金黄颜色、SO₂ 结合力增加、果香强度和风味长度下降；部分研究显示酯类和脂肪酸升高但整体感官影响因工艺而异（[Pickering, 1997](https://agris.fao.org/search/en/providers/125257/records/6765998d6784547a43e37328)）。 |
| 非酿酒酵母 | 将部分糖碳流转向甘油、有机酸、生物量或其他副产物；可降低乙醇得率，但效果菌株依赖；顺序接种可能消耗 YAN，影响后续 *S. cerevisiae* 发酵（[Gobert et al., 2017](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2017.02175/full)）。 | 可提升酯类、萜类释放、香气复杂度和风格差异；风险包括挥发酸、乙酸乙酯、残糖、停滞发酵和批次重现性差（[Penn State Extension, 2019](https://psuwineandgrapes.wordpress.com/2019/09/26/non-saccharomyces-yeast-in-winemaking/)）。 |
| 营养限制与温度控制 | YAN、氧、脂类和温度影响酵母生长、氮同化、酯类和高级醇生成；*S. cerevisiae* 通常需 120–140 mg N/L YAN，缺乏易导致滞缓或停滞发酵（[Gobert et al., 2017](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2017.02175/full)）。 | 可微调香气谱和发酵速率，但刻意营养限制可能导致还原味、挥发酸升高、残糖和微生物风险。应作为辅助控制，而非主要降醇策略。 |
| 纳滤（NF） | 通过压力驱动膜分离部分小分子，可用于糖或乙醇调整；低温操作有利于减少热损伤，但可能伴随小分子香气和部分基质损失（[Sam et al., 2021](https://agris.fao.org/search/en/providers/122535/records/65dff6c2b766d82b180398d9)）。 | 比热法温和，但若脱醇幅度大，香气削弱和口感变薄仍明显；膜污染和选择性限制影响实际效果。 |
| 反渗透（RO） | 低温、渐进式降低酒精；乙醇和水进入透过液，非挥发基质较多留在保留液；需多次循环，可能损失挥发性香气（[Winesecrets, 2024](https://winesecrets.com/the-art-and-science-of-dealcoholizing/)）。 | 适合小幅至中等酒精调整，热损伤少；但多次处理可能降低果香、花香和整体新鲜度。 |
| 渗透蒸馏（OD） | 依靠膜两侧浓度差或活度差转移乙醇；通常低温操作，可与 RO 组合；挥发性酯类和萜烯仍可能随乙醇损失（[Longo et al., 2024](https://link.springer.com/article/10.1007/s11947-024-03336-w)）。 | 相比高温蒸馏更温和，但无醇化或深度脱醇时仍会削弱香气强度和口感体积。 |
| 渗透汽化（Pervaporation） | 通过选择性膜使乙醇等挥发组分透过并在另一侧汽化；受膜材料、温度、蒸气压和化合物理化性质影响（[Sam et al., 2021](https://agris.fao.org/search/en/providers/122535/records/65dff6c2b766d82b180398d9)）。 | 对热敏组分较友好，但易带走高挥发香气；适合精细化分离，但工业成本和通量是限制。 |
| 旋转锥柱（SCC） | 真空低温薄膜蒸馏；可先在约 28–30°C 回收香气馏分，再约 38°C 去除乙醇并回配香气；为酿酒中广泛应用的脱醇技术（[Infowine, 2024b](https://www.infowine.com/en/wine-dealcoholization-most-used-techniques/)）。 | 香气回收能力较强，适合商业化；但深度脱醇仍会降低热感、酒体和果香，甚至出现氧化、酸感突出等问题（[Longo et al., 2024](https://link.springer.com/article/10.1007/s11947-024-03336-w)）。 |
| 真空蒸馏（VD） | 通过降低压力使乙醇约 40°C 蒸发，减少常压蒸馏热损伤；仍可能造成颜色、SO₂、挥发物和稳定性变化（[Infowine, 2024a](https://www.infowine.com/en/wine-dealcoholization-techniques-effects-and-current-challenges/)）。 | 较传统蒸馏温和，但可能降低果香、花香和新鲜度；温度、压力和脱醇幅度决定损失程度。 |
| 多级膜系统 | 将 RO 与 OD、透析等组合，先分离/浓缩再进一步脱醇或回配；研究显示 RO+OD 等膜组合在关键化合物保留和颜色稳定性上可优于部分热法（[IVES, 2025](https://ives-openscience.eu/52857/)）。 | 感官保留通常优于单一深度处理，但流程复杂、成本高；适合高品质低醇或无醇产品开发。 |
