# 系统性金融风险研究综述：理论基础与微观结构

本文将研究时间严格截断在 **2020年2月29日**：正文所依据的理论、模型、经验结果与文献均在该日之前已公开发表或发布。研究过程中仅使用独立的原始论文、专著、工作论文及期刊/研究机构的正式来源；用户明确排除的 *A Review of Micro-Based Systemic Risk Research from Multiple Perspectives* 及其相关页面未作为检索、阅读、论证或引文来源。

## 一、理论基础对比

### 金融加速器：从信用摩擦到宏观波动的内生放大

所谓“金融加速器”（financial accelerator），并不是泛指“一切金融因素放大经济周期”，而是指一类具有明确微观基础的信用摩擦机制：由于外部融资存在代理成本、信息不对称或抵押约束，借款人的资产负债表状况会改变其融资成本；宏观冲击因而通过净值、资产价格和信用条件的反馈被进一步放大。Bernanke、Gertler 与 Gilchrist（以下简称 BGG）是这一机制最有代表性的系统化表述者。其1996年论文 *The Financial Accelerator and the Flight to Quality* 将金融加速器解释为**贷款代理成本随经济周期内生变化**：衰退冲击削弱借款人的资产负债表，外部融资变得更昂贵，高代理成本借款人受到更严重的信贷收缩，因此小企业等融资约束更强的主体在衰退中受到不成比例的冲击。该文同时利用大小制造企业数据讨论了“向优质借款人转移”（flight to quality）的经验含义。[[1]](https://www.nber.org/papers/w4789)

BGG在1999年《宏观经济学手册》中的 *The Financial Accelerator in a Quantitative Business Cycle Framework* 则把这一思路正式嵌入动态一般均衡模型。其关键金融摩擦来自**有成本的状态验证（costly**** state ****verification）**：企业家投资项目面临个体收益风险，外部债权人不能无成本观察项目实现值，因此借款融资必须补偿监督和代理成本。结果是外部资金相对于内部资金存在“外部融资溢价”（external finance premium），而这一溢价与企业家净值负相关。净值越低，企业必须依赖越多外债，代理问题越严重，融资溢价越高。模型加入了货币、价格黏性、投资滞后和企业异质性，因此能够研究信用摩擦对货币政策和真实冲击的传播作用。[[2]](https://www.nber.org/papers/w6455)

其核心反馈可以概括为：

**负面宏观冲击**** → ****企业利润和资产价格下降**** → ****企业净值下降**** → ****外部融资溢价上升、可获得信贷下降**** → ****投资下降**** → ****产出和资产价格进一步下降。**

由此，金融部门主要起的是**放大器和持续器**作用。冲击本身可以来自技术、需求、货币政策等传统外生来源；信用摩擦并不一定是最初冲击，却使同样大小的冲击产生更大的投资和产出响应。BGG因此属于“外生冲击＋内生金融传播”的典型框架。[[3]](https://www.nber.org/papers/w6455)

这里需要将 BGG 与 Kiyotaki–Moore（1997）的机制准确区分。Kiyotaki 与 Moore 的 *Credit Cycles* 同样研究信用约束对周期的放大，但其核心不是有成本状态验证和外部融资溢价，而是**抵押约束与资产价格之间的反馈**。由于债权人只有在债务有抵押时才能有效实施偿付，耐久资产既是生产要素又是抵押物；资产价格下跌降低抵押价值，压低借款上限和投资需求，继而进一步压低资产价格。该模型说明，即使技术或收入分配冲击很小且短暂，也可能经“资产价格—抵押品—信用限额”机制产生较大且持久的产出和资产价格波动。[[4]](https://www.journals.uchicago.edu/doi/10.1086/262072)

因此，两者可被归入广义的资产负债表放大机制，但不能视为同一个模型。BGG的核心状态变量是**借款人净值以及由代理问题决定的融资溢价**；Kiyotaki–Moore的核心状态变量是**抵押品价值及其决定的借款约束**。前者更适合解释信用利差、企业融资条件和货币政策信用渠道，后者则突出资产价格与信贷容量的双向反馈。[[5]](https://doi.org/10.1016/s1574-0048%2899%2910034-x)

危机后的 DSGE 文献进一步把金融部门从简单的企业融资摩擦扩展到银行和金融中介。Christiano、Motto 与 Rostagno（2010）的 *Financial Factors in Economic Fluctuations* 在标准货币 DSGE 中加入银行部门、金融市场、代理问题和银行流动性约束，发现这些“金融因素”能够成为波动的重要触发和传播机制。[[6]](https://www.ecb.europa.eu/pub/research/authors/profiles/roberto-motto.en.html) 其后2014年的 *Risk Shocks* 更明确地在标准货币动态一般均衡模型中加入 BGG 金融加速器，并允许企业横截面个体不确定性的方差随时间变化；在其估计模型中，这种“风险冲击”成为美国商业周期的重要驱动力。这里的贡献是把原来较多作为传播器的金融摩擦部分转化为**冲击源本身**，但仍保留理性预期、均衡求解和显式微观合同结构。[[7]](https://www.aeaweb.org/articles?id=10.1257%2Faer.104.1.27)

**模型结论与经验含义应严格区分。** BGG模型推出的是一种条件性理论关系：净值下降导致融资溢价提高，从而放大投资和产出的响应；1996年的企业面板分析则为“融资受约束企业在衰退时受到更大冲击”提供经验支持。Christiano、Motto 与 Rostagno 关于“风险冲击最重要”的结论，则是特定估计 DSGE 结构和美国数据下的模型分解结果，不能直接解释为所有时期、所有经济体都由风险冲击主导。[[8]](https://www.nber.org/papers/w4789)

### Minsky金融不稳定性假说：稳定如何内生地产生危机

Hyman P. Minsky 的金融不稳定性假说（Financial Instability Hypothesis, FIH）采取了与上述 DSGE 信用摩擦明显不同的出发点。Minsky明确反对把资本主义经济理解为天然趋向稳定均衡的体系；在其框架中，复杂金融制度下的经济可以从自身内部产生金融脆弱性，不需要一个足够大的外生冲击才能解释危机。其1992年工作论文 *The Financial Instability Hypothesis* 将这一立场明确概括为对以稳定均衡为中心的传统分析的挑战，并强调资本主义体系内生动态以及政策、监管制度共同塑造商业周期。[[9]](https://www.levyinstitute.org/publications/the-financial-instability-hypothesis/)

FIH最著名的分析工具是三种融资状态。其划分依据不是资产是否盈利，而是一个经济主体的预期现金收入与债务支付承诺之间的关系：

**避险型融资（hedge** **finance）** 中，预期现金流足以支付利息和本金；**投机型融资（speculative** **finance）** 中，现金流能够支付利息，但不能完全偿还到期本金，因此必须滚动融资；**庞氏型融资（Ponzi** **finance）** 中，当前现金流甚至不足以支付全部利息，主体必须增加借款或依赖资产升值来维持债务。Minsky认为，当避险型融资占主导时，体系相对稳定；当投机型和庞氏型融资比重不断上升时，经济更可能成为一种“偏离放大型”体系。[[10]](https://www.levyinstitute.org/publications/the-financial-instability-hypothesis/)

FIH的核心命题由此形成：**长期稳定本身会改变主体行为，并逐步破坏产生稳定的条件。** 持续繁荣和较少发生违约，会降低市场参与者对风险的主观评估；企业、金融机构和投资者提高杠杆，接受更短期、更依赖再融资的负债结构，金融创新和竞争进一步放松过去的安全边际。结果是金融结构从避险型逐渐转向投机型乃至庞氏型。换言之，“稳定孕育不稳定”不是比喻，而是 FIH 中融资结构随繁荣内生演变的机制。[[11]](https://www.levyinstitute.org/publications/the-financial-instability-hypothesis/)

一旦利率上升、利润不及预期、资产价格停止上涨或者贷款人提高融资标准，投机型和庞氏型主体的再融资约束就会迅速暴露。它们出售资产、缩减投资或违约；抛售压低资产价格，使其他主体的净值和抵押价值恶化；银行变得更加谨慎，信用扩张转为收缩；投资下降又削弱总需求和企业利润，从而使原本只是金融部门的脆弱性进入实体经济。Minsky的论证尤其强调投资、利润和债务承诺之间的相互依赖：FIH并非一个“金融市场独立于实体经济”的故事，而是金融结构与投资支出共同决定宏观稳定性的理论。[[9]](https://www.levyinstitute.org/publications/the-financial-instability-hypothesis/)

FIH因而比传统 BGG 金融加速器更强调**历史时间、制度演化、杠杆选择和危机非线性**。在 BGG 的典型设定里，企业根据给定结构优化，经济在理性预期的一般均衡环境下响应随机冲击；在 Minsky 中，主体对稳定历史本身作出反应，其风险容忍度、融资惯例和金融创新改变了系统结构，所以脆弱性可以在表面低波动时期不断积累。[[12]](https://doi.org/10.1016/s1574-0048%2899%2910034-x)

### 两种理论的比较：外生冲击放大与内生脆弱性积累

两类理论并非互相排斥，它们观察的是金融体系动态的不同层面，但在关键假设和危机叙事上存在明显差异。

| 比较维度 | DSGE金融加速器 | Minsky FIH |
| --- | --- | --- |
| 基本问题 | 金融摩擦为何放大宏观冲击 | 繁荣为何会内生形成危机条件 |
| 代表机制 | 净值—外部融资溢价；或抵押品—信用约束 | 避险→投机→庞氏融资，杠杆与再融资依赖上升 |
| 关键摩擦/假设 | 信息不对称、代理成本、抵押约束；理性优化与均衡 | 债务承诺、历史形成的风险认知、制度与金融创新 |
| 冲击地位 | 经典 BGG 中多为外生冲击，经金融结构内生放大；后续模型允许金融风险冲击 | 严重不稳定可以主要由金融结构自身演进产生 |
| 主要状态变量 | 净值、杠杆、信用利差、抵押价值 | 融资结构、杠杆、现金流覆盖、再融资需求 |
| 非线性 | 可由约束、资产价格和金融摩擦产生，但基准模型通常围绕均衡分析 | 危机转折与融资制度变化具有核心地位 |
| 对实体经济的路径 | 融资条件恶化→投资/资本形成下降→产出、就业下降 | 信贷繁荣→脆弱化→再融资中断/资产抛售→投资与利润下降→债务紧缩 |
| 政策重点 | 降低金融摩擦、稳定净值/信贷供给，货币政策兼顾信用传导 | 抑制顺周期杠杆与金融创新带来的脆弱性；逆周期监管和最后贷款人作用更突出 |

BGG与Minsky最重要的共同点，是都否定“金融只是实体经济被动镜像”的观点。两者都认为资产负债表、杠杆和信贷条件可以反过来改变真实投资与产出。BGG的净值机制与 Minsky 的债务脆弱性因此存在某种经济学上的相似性：企业净值越薄、负债越重，对融资条件变化越敏感。Kiyotaki–Moore 的抵押品反馈更进一步说明资产价格下降如何缩小信用容量。[[13]](https://doi.org/10.1016/s1574-0048%2899%2910034-x)

真正的分界在于**不稳定从哪里来**。BGG基准模型主要回答“为什么一个给定冲击会被放大”；Minsky主要回答“为什么平静时期会使经济自身越来越容易受到冲击”。因此，如果研究问题是利率冲击如何经企业净值和信用利差进入投资，BGG框架更适合形成可估计、可定量反事实的模型；如果研究问题是多年信用繁荣为何逐步改变风险承担、融资期限和杠杆结构，Minsky的理论语言更直接。Christiano、Motto 与 Rostagno等危机后 DSGE 扩展实际上缩小了这一差距，因为金融风险开始被建模为重要冲击源，但这些模型仍没有完全等同于 Minsky 所强调的制度和行为内生演化。[[14]](https://www.aeaweb.org/articles?id=10.1257%2Faer.104.1.27)

政策含义也因此不同。金融加速器框架意味着，资产负债表恶化造成的融资溢价上升会使紧缩自我强化，所以稳定金融中介和借款人净值具有宏观价值；Minsky则进一步提出，仅在危机时稳定体系并不足够，因为长期成功的稳定政策也可能使私人部门相信风险已经降低，从而推动新的杠杆积累。两者结合起来，可以把系统性风险理解为两个阶段：**繁荣阶段形成脆弱性，危机阶段资产负债表与信用摩擦放大损失。** 这一“结合”是对两套理论的综合解释，而不是任何一篇原始论文的单一模型结论。[[15]](https://www.nber.org/papers/w6455)

## 二、微观结构研究

### 金融网络：连接既能分散风险，也能传播风险

金融网络研究把银行或其他金融机构作为节点，把银行间贷款、证券交叉持有、回购、衍生品或共同资产暴露看作连接。核心问题由此从“单家机构是否安全”变为“一个机构的资产如何同时成为另一个机构的负债，以及这种相互依赖如何改变系统对冲击的响应”。Eisenberg 与 Noe（2001）建立的清算网络模型是这一方向的重要数学基础：在一个由相互债务构成的体系中，各机构支付能力必须同时决定，并可在有限责任和债权优先规则下求得清算支付向量。由此，某一节点资产不足可以降低其向其他节点的偿付，形成直接的资产负债表外溢。[[16]](https://pubsonline.informs.org/doi/10.1287/mnsc.47.2.236.9835)

Allen 与 Gale（2000）的 *Financial Contagion* 提出了网络结构如何决定传染的重要早期结论。在其区域银行模型中，银行间债权原本用于对冲不同地区流动性需求，但这一风险分担结构同时创造了传染渠道。论文的关键模型结果是：较完整的银行间债权结构能够比不完整结构更好地分散局部冲击，而不完整网络更容易让冲击沿有限路径集中传播。[[17]](https://www.journals.uchicago.edu/doi/pdf/10.1086/262109) 这说明“更多连接必然意味着更大风险”并不是一般结论。

Gai 与 Kapadia（2010）进一步把这一问题发展为所谓 **“稳健但脆弱”（robust-yet-fragile）** 性质：金融网络在大多数冲击下可能表现得相当稳健，因此**发生系统性传染的概率较低**；但一旦冲击突破临界条件，网络连接会使损失传播到非常广的范围，因此**条件于传染已经发生，其规模可能极大**。这正是“robust”与“fragile”并存的含义，而不是说网络在同一意义上既稳定又不稳定。[[18]](https://www.bankofengland.co.uk/working-paper/2010/contagion-in-financial-networks)

Acemoglu、Ozdaglar 与 Tahbaz-Salehi（2015）进一步给出了清晰的“相变”结果。对于足够小的负面冲击，更密集、更多元化的银行间负债关系可以分摊损失，提高稳定性；但当冲击超过某个范围后，高度互联反而成为传播渠道，使系统更加脆弱。也就是说，同一个网络特征在不同冲击规模下可以具有相反的稳定性效应。[[19]](https://benny.aeaweb.org/articles?id=10.1257/aer.20130456) Elliott、Golub 与 Jackson（2014）也得到非单调结果：增加交易对手数量最初可能把原本分离的部分连接起来、让级联得以传播，但进一步增加分散化又可能降低每个单一交易对手违约所造成的损失。[[20]](https://benny.aeaweb.org/articles?id=10.1257/aer.104.10.3115)

因此，“复杂性”本身并不是一个足够的风险指标。Haldane 与 May（2011）借鉴生态网络研究指出，金融网络的连接度、规模、同质性与复杂性组合起来可能改变稳定性，微观层面的分散化并不保证系统层面的分散化。[[21]](https://www.nature.com/articles/nature09659) Gai、Haldane 与 Kapadia（2011）在包含无担保银行间债权、回购和抵押品折扣冲击的模型中进一步表明，网络复杂性和集中度可以放大资金流动性危机，并允许融资冲击通过银行间连接广泛传播。[[22]](https://www.sciencedirect.com/science/article/pii/S0304393211000481)

**核心—边缘（core-periphery）结构**则是从真实银行间数据中反复观察到的重要拓扑形式。Craig 与 von Peter（2014）利用德国银行体系1999—2012年的双边银行间敞口发现，市场不是所有银行随机、均等相连的“平面网络”：大量外围银行并不彼此直接交易，而主要通过少数“货币中心银行”中介；这些核心银行彼此高度连接，同时连接大量外围银行。这种分层结构可由核心—边缘模型显著优于标准随机网络地描述。[[23]](https://www.sciencedirect.com/science/article/pii/S1042957314000126)

核心—边缘结构的系统性含义是双面的。正常时期，核心机构集中匹配流动性，降低外围机构之间直接建立大量关系的成本；压力时期，核心机构的高连接度意味着其失灵可能同时影响许多外围节点。Battiston 等人（2012）提出 DebtRank，就是为了衡量一个节点通过金融敞口网络影响整个体系经济价值的能力，强调“规模大”之外还存在“网络中心性”这一系统重要性维度。[[24]](https://www.nature.com/articles/srep00541)

因此，网络研究最重要的结论不是“互联越多越危险”，而是：**风险分散效应与传染效应同时存在，净结果依赖冲击大小、资本缓冲、网络集中度、敞口规模和拓扑。** 这也是“稳健但脆弱”现象真正的理论含义。[[25]](https://www.bankofengland.co.uk/working-paper/2010/contagion-in-financial-networks)

对实体经济而言，网络级联如果使多家银行同时损失资本或无法取得银行间融资，就会迫使它们同步缩表；与单一银行受到冲击相比，这类同步去杠杆更可能压缩对企业和家庭的贷款，并使金融冲击变成总量信用冲击。Gai、Haldane 与 Kapadia的模型因此把银行间资金传染直接与系统性流动性危机联系起来。[[22]](https://www.sciencedirect.com/science/article/pii/S0304393211000481)

### 市场流动性：融资约束与价格冲击形成流动性螺旋

Brunnermeier 与 Pedersen（2009）的 *Market Liquidity and Funding Liquidity* 是理解系统性流动性风险的关键文献。两位作者严格区分了两个概念：**市场流动性（market** **liquidity）**是以接近基本价值的价格迅速买卖资产的容易程度；**融资流动性（funding** **liquidity）**则是交易者获得资金、满足保证金和融资需求的能力。二者不是独立风险，而是通过资产负债表互相决定。[[26]](https://doi.org/10.1093/RFS/HHN098)

其基本逻辑是，证券交易商、套利者和其他资金约束投资者通常是市场流动性的提供者。当他们资金充足时，会在价格偏离基本价值时买入，从而提高市场深度；但其交易能力取决于自有资本以及借款所需的保证金。如果损失侵蚀资本或融资方提高保证金，交易者可使用的杠杆下降，只能减少头寸甚至出售资产。与此同时，市场流动性越差、价格波动越大，贷款方通常要求越高的保证金；于是融资流动性恶化又进一步破坏市场流动性。Brunnermeier 与 Pedersen证明，在一定条件下，这种互相强化可产生**流动性螺旋（liquidity** **spiral）**。[[27]](https://doi.org/10.1093/RFS/HHN098)

该文通常区分两种相互关联的螺旋。

**损失螺旋（loss** **spiral）**是：资产价格下跌 → 杠杆投资者蒙受损失 → 净资本下降 → 为满足融资约束而减仓 → 卖压导致价格进一步下降 → 新一轮损失。

**保证金螺旋（margin** **spiral）**则是：价格波动和流动性风险增加 → 融资方提高保证金或 haircut → 同样资本能够支持的头寸减少 → 杠杆投资者被迫出售 → 市场流动性进一步下降、波动进一步上升 → 保证金继续提高。其关键在于保证金在压力时期可能具有顺周期性，而不是始终发挥稳定作用。[[27]](https://doi.org/10.1093/RFS/HHN098)

这两种机制说明，高杠杆不是单纯增加一家机构的损失幅度，还会改变该机构面对损失时的**交易行为**。当多家机构同时采用类似的风险管理规则或融资方式时，单个机构理性的去杠杆会变成系统性的资产抛售。因此，流动性风险带有典型的宏观外部性：个体出售资产是为了保存资本，但所有主体同时出售会降低所有人的资产价值。

Cifuentes、Ferrucci 与 Shin（2005）将这一思想放入由金融机构组成的资产负债表体系：机构受偿付能力约束，同时以市价计量资产；只要非流动资产需求曲线不是完全有弹性的，受压机构的出售就会压低价格，市价损失使其他机构也违反资本约束并出售，进而形成新一轮价格下跌和出售。其模型明确表明，即使初始冲击很小，也可能在“市价计量—资本约束—资产出售”反馈下造成传染性失败。[[28]](https://academic.oup.com/jeea/article-abstract/3/2-3/556/2281473)

Greenwood、Landier 与 Thesmar（2015）把这一机制应用于银行共同资产持有。当银行资本遭受冲击后，如果希望恢复目标杠杆，就需要出售资产；如果潜在买家有限，出售产生价格冲击。其他持有相同资产的银行因此出现账面损失，也必须去杠杆，于是单家银行的资产负债表调整变成系统性火售。作者利用欧洲银行资产负债表展示了如何度量银行对全系统去杠杆的脆弱性及单家银行所产生的外溢。[[29]](https://ideas.repec.org/a/eee/jfinec/v115y2015i3p471-485.html)

Cont 与 Schaanning（2017）进一步把这种机制明确称为**价格媒介的间接传染**。他们的压力测试模型中，宏观损失与资本或杠杆约束相互作用，引发资产清算；资产出售降低价格，其他机构因共同资产持有而蒙受损失，再触发后续出售。其“流动性加权的投资组合重叠”刻画了一个机构即使没有直接向另一个机构放贷，也能通过共同资产市场受到后者影响的程度。[[30]](https://www.norges-bank.no/aktuelt/publikasjoner/Working-Papers/2017/22017/)

实体经济传导由此有两条主要路径。一是资产价格下跌直接削弱银行和企业净值，并通过类似金融加速器的机制抬高融资成本；二是银行为了恢复杠杆和流动性指标，不仅出售证券，也可能压缩对非金融企业和家庭的信贷。因此，市场流动性危机可以最终表现为实体经济中的融资收缩、投资下降和产出减少。这里可看到宏观金融加速器和微观流动性研究的连接：前者强调净值下降如何影响融资条件，后者解释净值为什么可能因火售和市场深度不足而在全系统同步下降。[[31]](https://doi.org/10.1016/s1574-0048%2899%2910034-x)

### 金融传染：直接违约链与间接价格传染

“金融传染”不是单一机制。若按照**传染是否通过合同上的直接金融敞口发生**这一标准，截至2020年初最清晰、最有分析价值的二分法，是**直接传染**与**间接传染**。

**直接传染（direct**** / counterparty / default ****contagion）**发生在金融机构之间存在银行间贷款、衍生品、回购或其他债权债务关系时。机构 A 违约使其债权人 B 的资产价值下降；如果 B 的资本不足，B 也可能违约，从而损害 C，形成违约链条。Eisenberg 与 Noe（2001）的清算模型是这类机制的标准基准：所有机构的实际偿付额相互依赖，某个债务人的支付不足会直接减少其债权人的资产，并通过网络反馈影响最终清算结果。[[16]](https://pubsonline.informs.org/doi/10.1287/mnsc.47.2.236.9835)

直接传染的强弱取决于敞口集中度、资本缓冲、回收率以及网络结构。Allen–Gale、Gai–Kapadia、Elliott–Golub–Jackson 与 Acemoglu–Ozdaglar–Tahbaz-Salehi分别说明，风险分担与传染之间存在非单调权衡，因此不能仅凭“连接数”判断直接传染风险。[[32]](https://www.journals.uchicago.edu/doi/pdf/10.1086/262109)

**间接传染（indirect**** / common-asset / fire-sale / price-mediated ****contagion）**则不要求 A 欠 B 钱。假设 A 与 B 都持有资产 X；A 遭受损失后被迫出售 X，X 的价格因市场深度有限而下跌，B 对 X 的持仓产生市价损失，于是 B 也可能被迫出售。A 与 B 之间并没有合同连接，却通过**市场价格**形成了经济上的“间接敞口”。Cifuentes、Ferrucci 与 Shin（2005）、Greenwood、Landier 与 Thesmar（2015）以及 Cont 与 Schaanning（2017）分别从资本约束、市价计量、目标杠杆和投资组合重叠等角度建立了这一类火售传染机制。[[33]](https://academic.oup.com/jeea/article-abstract/3/2-3/556/2281473)

两类传染可以相互强化。例如，银行遭受交易对手违约损失后可能违反资本约束，于是出售共同资产；火售价格下跌又使其他银行出现账面损失，进一步引发违约。因此，“直接网络”与“共同资产网络”并不是彼此独立的现实系统，而是理论上可以区分、危机中可以叠加的两个层次。Gai、Haldane 与 Kapadia关于无担保敞口、回购和 haircut 的联合分析即说明，资金流动性与银行间网络可以共同传播危机。[[22]](https://www.sciencedirect.com/science/article/pii/S0304393211000481)

除上述二分法外，文献还经常讨论**流动性传染**和**信息/预期传染**，但这属于不同分类维度，不能简单当作与“直接/间接”互斥的第三、第四类型。流动性传染是指一家机构因失去短期融资、回购融资或存款而被迫缩表，并通过资金市场把压力传给其他机构；Gai、Haldane 与 Kapadia的模型就是典型例子。[[22]](https://www.sciencedirect.com/science/article/pii/S0304393211000481) 信息或信心渠道则指某家机构暴露问题后，市场参与者推断其他具有类似资产、业务或融资结构的机构也存在风险，因而提高融资条件或撤回资金。它可能没有初始的直接债权损失，却能触发融资流动性紧缩，并最终产生火售。因此，“基本面/信息传染”是一种按照**触发信息的来源**进行的分类，而“直接/间接传染”则是按照**损失传播介质**进行分类，两者不能混为一谈。

从系统性风险角度看，这一区分具有重要监管含义。只测量银行间双边贷款能够识别一部分直接传染，却可能漏掉共同资产持仓造成的巨大间接敞口；反过来，只做单家银行资产价格压力测试，也可能漏掉违约清算和融资网络。Cont 与 Schaanning的结果尤其强调，机构的风险不只取决于自己的资产，还取决于**其他大型、高杠杆投资组合持有什么、以及这些资产有多不流动**。[[30]](https://www.norges-bank.no/aktuelt/publikasjoner/Working-Papers/2017/22017/)

整体上，微观结构研究把系统性风险从“坏资产造成损失”的静态问题转化为一个**反馈与相互依赖问题**。直接敞口造成偿付链，网络连接决定损失如何跨机构传播；共同资产造成价格媒介传染；融资约束把价格下降转化为被迫出售；核心—边缘结构和高度集中节点又决定冲击能否迅速进入整个系统。因而，系统性风险大小不能从机构风险的简单加总得到，而取决于银行间合同网络、资产持仓网络以及流动性约束三者的联合结构。[[34]](https://pubsonline.informs.org/doi/10.1287/mnsc.47.2.236.9835)
