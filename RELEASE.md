# CompareDR public resources

Copyright (c) 2026 LongCat

This release contains the evaluation pipeline, experimental code, offline
reproduction resources, 360 main9 reports, 280 studies7 reports, human preference
labels, controlled revisions, and the manuscript-aligned website. Collection
counts include repeated reports across cohorts. The numerical and experimental
inputs are preserved from the frozen source package; public-facing repository
links and license notices are maintained separately.

The new `website/longcat-blog/` package adds a bilingual two-tab article and a
versioned JSON leaderboard feed. Deploy only its `dist/` directory to the LongCat
blog host; update the feed through repository review after deployment.

The CompareDR arXiv and Hugging Face publications are separate release steps.
No identifier or URL is asserted until confirmed. LongCat-DeepResearch's existing
technical report and research-harness code are linked from the blog.

`SOURCE_PACKAGES.json` records the historical input package receipts, not a
claim that the current public-facing files match those earlier website archives
byte for byte. Scientific input hashes and report manifests remain authoritative.
