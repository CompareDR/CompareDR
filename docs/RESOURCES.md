# Resource map

| Layer | Entry | Inputs | Outputs |
|---|---|---|---|
| Evaluate reports | `evaluation/run.py` | Full reports + query-specific criteria + configured providers | Graphs, rationales, verification cards, PT/PW decisions, ordinal scores |
| Reproduce published numbers | `experiments/run.py` → `reproduction/offline/reproduce.py` | Frozen decisions, scores, labels and trials | All 16 tables + numerical audit; no model calls |
| Present results | `website/sync_comparedr.py` | Manuscript-aligned result snapshots and templates | Full-dimensional README/leaderboard tables, `website/dist/`, CSV/JSON; local build only |
| Submit another system | `submissions/validate.py` and the GitHub submission form | 40 reports + system metadata manifest | Format check and a package for maintainer review; no automatic evaluation |

## Leaderboard and submission entry points

- [Repository homepage](../README.md#leaderboard-and-main-results) and
  [leaderboard reference](../LEADERBOARD.md) both show the complete five dimensions
  plus overall score, generated by the same table renderer.
- [Website homepage](../website/dist/index.html) and
  [standalone leaderboard](../website/dist/leaderboard.html) show the same scores
  with interactive sorting; open the HTML locally to use the interactive pages.
- [CSV](../website/dist/leaderboard.csv) and
  [JSON with protocol metadata](../website/dist/leaderboard.json) retain full precision.
- [Submission format](../submissions/README.md),
  [template ZIP](../website/dist/submission-template.zip), and
  [GitHub submission form](https://github.com/CompareDR/CompareDR/issues/new?template=submit-system.yml)
  provide the public intake path. Sign in to GitHub to submit an issue.

The generation source is the saved manuscript-aligned result snapshot, not a
separately edited table for each destination. Rebuild before synchronizing the
repository and website snapshots to keep the displayed results consistent.

## Main algorithm

| Component | Implementation |
|---|---|
| Portable CLI, frozen input preparation | [`evaluation/run.py`](../evaluation/run.py) |
| Complete per-query execution | [`evaluation/pipeline.py`](../evaluation/pipeline.py) |
| Segmentation and reference binding | [`evaluation/common.py`](../evaluation/common.py), [`minimax_adapter.py`](../evaluation/minimax_adapter.py) |
| PT/PW prompts, graph extraction and localization | [`evaluation/vendor/iclrbench_runs/`](../evaluation/vendor/iclrbench_runs/) |
| Original-reference-first acquisition | [`acquisition_fix.py`](../evaluation/acquisition_fix.py) |
| Public-address checks, deadlines, HTML/PDF parsing | [`retrieval_resilient.py`](../evaluation/retrieval_resilient.py) |
| Complete-report readability judging | [`readability_raw.py`](../evaluation/readability_raw.py) |
| Output validation and bounded format repairs | [`soft_contracts.py`](../evaluation/soft_contracts.py), [`compat.py`](../evaluation/compat.py) |
| Explicit verification-failure accounting | [`verification_fallback.py`](../evaluation/verification_fallback.py) |
| Coverage checks and response provenance | [`completeness.py`](../evaluation/completeness.py) |
| Shared rate/concurrency limits | [`global_limits.py`](../evaluation/global_limits.py) |
| Final five-level ordinal fit | [`ordinal_model.py`](../evaluation/ordinal_model.py), [`aggregate.py`](../evaluation/aggregate.py) |

The dependency modules retain their source filenames to make the implementation
traceable. They are not separate recommended command-line entry points. Start
with `evaluation/run.py`; do not run historical vendor demo `main()` functions.
The publication score is the ordinal aggregate, **not** the per-query arithmetic
diagnostic written by `scoring.py`.

See [the experiment map](../experiments/README.md) for every table's computation.
See [data identities and schemas](DATA.md) before joining report, score or label
files. No original workstation or external disk layout is needed for the documented
workflows. The paper flowchart is the exact PDF and a rendered PNG. An editable
drawing is not claimed when its correspondence to that PDF has not been verified.
